小驴人脉把联系人、关系和共同经历放进思源工作空间。每个人对应一篇普通思源文档，结构化资料保存在关联的思源数据库中，可以继续使用思源的搜索、双链和同步能力。

## 本次更新（v0.5.6 · 2026-10-11）

本版本完成独立内核与真实 browser-desktop 联合验收，修复测试认证清理边界，并继续收口联系人资料编辑和组织管理体验。

新增：真实前端独立内核验收

- 增加真实 browser-desktop 双页面、组织成员、组织归档恢复、生日、账本、别名、跟进和跨窗口联动验收记录。
- 独立内核写入、重启回读、迁移恢复和发布产物均使用隔离工作区，不接触用户笔记。

新增：联系人创建前置设置

- 新建联系人填写关系称谓时，可直接创建或指定“我”的档案；前置条件失败不会留下半成品，当前草稿和补充资料会保留。

优化：独立内核 E2E 认证与清理

- 真实前端页面在首屏导航前注入独立内核 `api.token`，第二页面也在导航前完成认证，避免匿名请求触发内核失败认证限流。
- 测试完成后可靠清理临时笔记本，认证失败不再掩盖业务验收结果。

优化：本人资料编辑与异步状态

- “我自己”编辑页显示工作单位和学校选择，隐藏不适用的自身关系称谓，并在资料读取期间保持稳定加载态。
- 导入、批量操作和资料编辑的忙碌按钮统一禁用，避免重复提交或在异步读取期间误关闭页面。

修复：相关人读取与本人入口

- 兼容思源对空关系单元格省略 `relation` 或 `blockIDs` 的返回形态；非空非法关系数据仍会阻断写入并提示核实。
- 统一首页、搜索和详情入口的本人标记，修复从部分入口打开“我自己”时无法维护组织归属的问题。

修复：E2E 清理认证边界

- 修复新版思源内核使用 `conf.api.token` 时真实浏览器首屏请求未携带 `Authorization` 的问题，清理阶段不再出现 `Too many failed authentication attempts`。
- 修复第二隔离页面先导航后认证造成的竞态。

## 主要功能

| 能力 | 说明 |
|---|---|
| 联系人名册 | 卡片与表格视图、搜索、分组与组合筛选、保存视图、资料补录、批量收编已有笔记和疑似重复提示 |
| 通讯录与快速录入 | 导入 vCard 2.1/3.0/4.0 文件，导出 vCard 3.0；粘贴名片或聊天文字识别资料，也可从编辑器选区或整篇笔记识别 |
| 人物资料 | 本人档案、人物别名、与我的关系称谓、人物文档档案条和可写回人物文档的独立备注 |
| 关系与组织 | 双向人物关系、关系图与文档引用图；组织及多段成员历史、共同背景和关系查询 |
| 互动与捕获 | 从会议笔记捕获参与者和共同经历；互动时间线、备注模板、往来账本、交往回顾报表和会面简报 |
| 提醒与跟进 | 公历/农历生日、联系节奏、久未联系提醒；跟进事项可同步为人物文档中的思源原生任务块 |
| 资料检查与插件桥接 | 只读资料体检并跳转处理；通过 `window.LvContacts` 为其他插件提供选人、建人和记录共同经历的能力 |
| 移动布局 | 响应式工作台与全屏弹窗，移动视口有隔离回归覆盖 |

## 安装

当前建议通过 GitHub Release 手动安装；集市上架 PR 已合并，但客户端可见性尚未在真实设备核验。

1. 从 [v0.5.6 Release](https://github.com/ai68298100/siyuan-contacts/releases/tag/v0.5.6) 下载 `package.zip`。
2. 将压缩包内容解压到思源工作空间的 `data/plugins/siyuan-contacts/`，确认 `plugin.json` 位于该目录根部。
3. 重启思源，在“设置 → 集市 → 已安装”中启用“小驴人脉”。

要求：思源笔记 **3.8.5 或更高版本**。

## 快速开始

1. 点击思源顶栏的人脉图标，按向导建立联系人笔记本和数据库。
2. 在联系人页新建人物、收编已有笔记、导入 `.vcf`，或粘贴文字识别资料。
3. 在人物详情中维护关系、组织归属、独立备注和往来记录。
4. 在会议笔记中右键选择“人脉：捕获本文人员”，记录参与者与共同经历。
5. 在首页查看生日、联系提醒和待跟进事项；卸载前先导出插件数据迁移包。

## 数据与隐私

联系人文档、人物独立备注和联系人数据库属于思源工作区内容。插件不发送遥测；AI 识别只在用户主动操作时调用思源配置的 AI 服务，相关笔记内容会发送给该服务。

互动、跟进、联系节奏、提醒暂缓、收编索引、模板、往来账本、别名、本人身份、组织成员、组织资料和关系称谓等插件自管数据保存在思源的插件数据目录。卸载或删除插件数据前，请先在“设置 → 导出中心”导出插件数据迁移包。

迁移包是带差异预览的 JSON 快照，不是工作区备份或字节级备份。它包含 12 类插件自管数据，但不包含人物/组织文档、联系人数据库、数据库锚点、界面偏好和未完成操作断点。跨工作区迁移时，先通过思源迁移人物和组织文档及数据库，再在插件中重绑数据库，最后导入迁移包；插件不会按姓名猜测文档对应关系。

## 已知限制

- 隔离浏览器和内核回归不等于真实宿主验收；真实用户工作区、Android 真机、软键盘/安全区和真实多窗口仍需验证。
- 思源原生图入口、任务管理器互读及集市客户端可见性尚未验收；当前请按上方步骤手动安装。
- 插件界面英文翻译尚未完整，部分内容可能显示为中文。
- 当前不支持 CardDAV 通讯录或 CalDAV 日历在线同步；通讯录交换通过 vCard 文件完成。

各项验证范围见 [v0.5.6 发布说明](docs/RELEASE-NOTES-v0.5.6.md)。

## 开发

需要 Node.js 24 或更高版本、pnpm 12.x。安装依赖后启动思源，首次调试先运行 `pnpm make-link` 配置热重载链接，再运行 `pnpm dev`。

常用检查：`pnpm check`、`pnpm test`、`pnpm test:ui`、`pnpm test:ui:mobile`、`pnpm build`、`pnpm check:release`。移动视口测试不代表真机验收。

开发约定见 [AGENTS.md](AGENTS.md) 和 [开发交接](docs/HANDOFF.md)，存储边界见 [数据契约](docs/DATA-CONTRACT.md)，完整变更记录见 [CHANGELOG](docs/CHANGELOG.md)。
