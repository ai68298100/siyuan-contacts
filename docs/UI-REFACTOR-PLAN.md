# UI 改造排期表（UI-REFACTOR-PLAN）

> 事实源：docs/UI-HANDOFF.md §4；视觉蓝图：docs/ui-prototype.html；令牌：src/style/_tokens.scss。
> 本表只覆盖**界面层改造**，不动数据契约（DATA-CONTRACT 各锚点/字段/事件格式全部保持不变）。
> 工作量单位：人日（d），按"熟悉仓库的开发者 + AI 辅助"估算，含自测不含联调等待。

## 优先级排序依据

1. **基础设施先行**：令牌接入（UI-01）与对话框原语（UI-02）是其余所有任务的公共依赖，先做可避免后续返工。
2. **高频路径优先**：联系人列表 + 详情是约 80% 使用时长的路径（UI-04/UI-05），紧随其后的是承载它们的导航骨架（UI-03）。
3. **发布门禁对齐**：M5 门禁项中"设置页（字段降级重建入口，D-0006）"与"移动端真机验证"分别对应 UI-06 与 UI-10，须在进入发版流程前完成。
4. **低频流程靠后**：捕获/导入是低频（人均每周 ≤1 次）且当前功能完整，视觉升级放 P2/P3。
5. **移动端最后一次性过**：待桌面形态稳定后再做布局级适配，避免两套形态反复拉扯。

## 任务明细

### UI-01 令牌接入与历史样式迁移（P0 / 0.5d）
- **范围**：`src/index.scss` 已 `@use "style/tokens"`（已就位）；将历史样式中的 b3 直引与字面值逐步替换为 `--lvct-*` 令牌：弹窗遮罩 `rgba(0,0,0,.35)` → `color-mix` 派生；图谱分组色硬编码 → `var(--lvct-group-*)`；圆角/间距字面值就近收敛。
- **不做**：不改任何组件结构与类名；不产生视觉变化（允许像素级差异）。
- **验收**：`pnpm build` 通过；明暗主题下各视图无回归；`Grep "rgba\(|#[0-9a-fA-F]{3,6}" src/index.scss` 命中数显著下降（遮罩/分组色清零）。

### UI-02 对话框原语统一（P0 / 1.5d）
- **范围**：自绘 `.lvct-dialog-mask`（详情/新建/编辑/导入/vCard 五处）收敛为一个共享 Svelte 组件 `LvctDialog`：ESC 关闭、焦点陷阱、打开时焦点落首个可交互元素、关闭后焦点归还、有未保存修改时二次确认；宽度走 `--lvct-dialog-w(-wide)`；遮罩加 `backdrop-filter: blur(2px)`。原生 `Dialog`（捕获弹窗）保留，补 ESC 行为一致性。
- **依赖**：UI-01（令牌）。
- **验收**：键盘-only 可完成新建联系人全流程；Tab 不出弹窗；五处弹窗全部走共享组件。

### UI-03 工作台导航：顶部 Tab → 左侧栏（P1 / 2d）
- **范围**：`Workbench.svelte` 重构为「196px 侧栏 + 页头 + 内容区」骨架（原型 s-home/s-people 帧）；侧栏含品牌区、视图项（首页/联系人/图谱 + 二期「组织/建议」占位 disabled）、底部设置入口；页头含视图标题、全局搜索框（先接通联系人搜索）、主操作按钮。移动端工作台保留全屏容器，导航由同一组视图项切换为底部 Tab。
- **依赖**：UI-01。
- **注意**：视图切换逻辑（`current: ViewId`）不变；详情弹窗承载在 UI-05 移交 Peek 后从 Workbench 摘除。
- **验收**：三视图切换正常；宽≥768px 显示侧栏；占位项可见但禁用。

### UI-04 联系人列表对齐（P1 / 2.5d）
- **范围**：`PeopleView.svelte` + `PersonCard.svelte`：
  ① 统一主操作——卡片与表格点击**均打开 Peek**（Peek 由 UI-05 提供，本任务先以现有详情弹窗顶替占位）；「打开文档」收敛为悬停出现的图标钮（卡片）与行内图标（表格）；
  ② 工具栏补齐：排序下拉（最近互动/姓名/生日临近）、标签多选筛选、已选筛选 chip 行；
  ③ 表格多选 + 底部批量操作条（改分组/加标签/导出 vCard——导出可直接复用现有 vCard 服务，改分组/加标签为批量 `setAttributeViewBlockAttr`）；
  ④ 加载态换骨架屏（组件规范 §Skeleton）。
- **依赖**：UI-03（新骨架内的工具栏区）。
- **验收**：卡片/表格点击行为一致；筛选+排序+搜索可叠加；批量导出与单导结果一致。

### UI-05 人物详情 Peek 侧栏（P1 / 3d）
- **范围**：`PersonDetail.svelte` 从居中弹窗改为右侧 400px Peek（原型 s-detail 帧）：
  ① 头部：头像/姓名/徽标行 + 常驻操作组（编辑资料、打开文档、更多→删除、关闭），上一条/下一条翻阅；
  ② 三区 Tab：概览（字段 dl + 下次提醒 + 记一笔互动常驻）/ 互动（完整时间线，迁自现有「互动与共同出席」）/ 相关人（chip 管理，迁自现有）；
  ③ 编辑入口复用 `PersonEditDialog`；删除走二次确认 + 先解绑行（DATA-CONTRACT §1.3）；
  ④ 点击外部不关闭（防误丢输入），Esc/✕ 关闭。
- **依赖**：UI-02（复用 LvctDialog 模式与焦点管理）、UI-04（列表选中态联动）。
- **验收**：列表→Peek→文档三级深度畅通；编辑/删除在 Peek 内可达；翻阅多人时列表选中同步。

### UI-06 设置页落地（P1 / 3d）★ M5 门禁
- **范围**：当前 `openSettings()` 仅为 toast（空壳）。新建设置视图（左侧分栏右侧内容，原型 s-settings 帧）：
  ① 通用：默认视图/默认排序/启动打开工作台 → 写入 `view-preferences.json`（契约 §3 已预留）；
  ② 数据与字段：**字段健康检查**（以 fieldMap 对照 `renderAttributeView` 列，缺列列出并给一键重建，落实 D-0006「锚点失效给重建入口，不做静默自愈」）、重新绑定锚点、导出（vCard + 互动事件 JSON）；
  ③ 提醒：生日窗口/久未联系阈值/启动提醒；
  ④ AI 与隐私：AI 总开关（关闭后隐藏捕获弹窗「AI 分析本页」等全部入口）、数据边界说明；
  ⑤ 服务桥：LvContacts 协议状态与 capabilities 展示；
  ⑥ 关于：版本/文档链接。
- **依赖**：UI-01。偏好读取需在 UI-04 排序/视图默认值处生效（两任务互相接口对齐：偏好键名以本任务为准并登记进 DATA-CONTRACT §3）。
- **验收**：每项设置持久化并生效；删掉数据库一列后健康检查报缺并可重建；AI 关闭后全插件无 AI 入口。

### UI-07 仪表盘增强（P2 / 1.5d）
- **范围**：`DashboardView.svelte`：问候语 + 今日生日横幅；四统计卡可点击（跳转联系人页并带对应筛选）；久未联系卡内嵌「记一笔」快捷输入（复用 UI-05 的记录组件）；骨架屏；空态按组件规范给 1–3 个下一步。
- **依赖**：UI-03。
- **验收**：统计卡点击 = 对应筛选结果；快捷记录后 staleness 即时刷新（名册缓存失效链路现有）。

### UI-08 关系图谱工具栏（P2 / 2d）
- **范围**：`RelationGraph.svelte`：搜索定位（命中节点居中高亮）、分组过滤 chip 组（与 `capGraph` 截断联动，截断提示改为"已截断 · 建议用分组过滤"并可操作）、缩放控件（cytoscape zoom API）与适应按钮、节点悬停卡（分组/度数/最近互动/共同联系人）。
- **依赖**：UI-01（分组色令牌）。
- **验收**：截断提示与过滤控件闭环；悬停卡 300ms 延迟出现；明暗主题边/字色正确（现有运行时取色保留）。

### UI-09 捕获弹窗三步向导（P2 / 2d）
- **范围**：`CaptureDialog.svelte` 重构为 识别 → 确认 → 完成 三步（原型 s-capture 帧）：步骤条；双链识别结果标「双链」徽标、AI 提名标「AI 提名」徽标（AI 只提名不决定，勾选才落库——现有逻辑保留，仅呈现分层）；提交进度条；完成页给可跳转结果摘要（打开人物/查看写入区块）。
- **依赖**：UI-02。
- **验收**：幂等语义不变（source+externalRef）；AI 关闭时步骤一不出现 AI 按钮（与 UI-06 联动）。

### UI-10 移动端布局级适配 + 真机验证（P2 / 2.5d）★ M5 门禁
- **范围**：底部 Tab Bar（首页/联系人/图谱/设置）；Peek → 全屏底部抽屉；卡片单列；统计卡 2×2；触控目标 ≥ `--lvct-touch-min-mobile`；安全区适配。判定一律 `getFrontend()`（铁律 8）。
- **依赖**：UI-03~06 桌面形态稳定后开工。
- **验收**：M5 真机清单全过（触控/安全区/键盘弹起不遮输入）。

### UI-11 导入/vCard 弹窗与空状态全局规范化（P3 / 1d）
- **范围**：`ImportDialog`/`VCardDialog` 走 LvctDialog 宽版；进度/结果页对齐捕获向导样式；全插件空状态统一为「图标 + 一句引导 + 1–3 个行动按钮」；剩余纯文本加载态清零。
- **依赖**：UI-02、UI-07。

### UI-12 人物文档档案条升级（P3 / 1d）
- **范围**：`panels/person-panel.ts`：档案条升级为「头像 + 徽标行（分组/生日倒计时/最近互动）+ 字段行 + 编辑资料/打开人脉」（原型 s-docbar 帧）；为二期「会前简报」预留可折叠卡槽位。
- **依赖**：UI-01。

## 执行守则

- 每个任务单独提交；完成即更新 docs/PROGRESS.md 并在本表勾选。
- 涉及偏好键/设置存储变更 → 先改 DATA-CONTRACT §3 再改代码（契约铁律）。
- 视觉一律以 docs/ui-prototype.html 对应帧为准；偏差超过令牌体系能解释的范围时，先改原型再改代码（原型是上游）。
- 每任务完工跑 `pnpm check && pnpm test`；架构守门（tests/architecture.test.ts）不许破。
