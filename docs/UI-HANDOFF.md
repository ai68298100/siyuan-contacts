## 1. 产品一页看懂

小驴人脉（siyuan-contacts）：思源笔记插件，**在笔记里管理人脉**——每个联系人 = 一篇普通思源文档 + 原生数据库（AV）里绑定的一行；插件提供管理界面（工作台：首页/联系人/关系图谱）。联系人文档和数据库是思源原生数据；互动事件、插件设置和偏好在插件自管目录，卸载并删除插件数据时可能丢失，详见 `docs/DATA-CONTRACT.md` §0。已实现 M1–M4 的主要功能；M5 发版判断仍需原型对齐和发布范围确认。

必读上游文档（按优先级）：`README.md`（功能）→ `AGENTS.md`（铁律，违反会被架构测试拦住）→ `docs/DATA-CONTRACT.md`（存储边界）→ `docs/ROADMAP.md`（演进方向）。

## 2. 设计原则（五条，评审争议时据此裁决）

1. **思源原生感**：颜色一律 b3 变量桥接、控件形态对齐思源设置页，插件像"长出来"的。
2. **双向出入口**：人脉活在文档里——文档可进（档案条/反链），插件可出（打开文档/写参与人员区块）。
3. **渐进披露**：列表 → Peek 侧栏 → 完整文档，三级详情深度，默认不打断当前任务。
4. **本地可信**：AI 一律显式触发、可全局关闭；任何数据外发在界面明示。
5. **为演进留白**：导航/筛选/设置分区为二期「组织、关系库、AI 建议」预留扩展位。

## 3. 令牌文件使用指南（`src/style/_tokens.scss`）

### 3.1 三层架构（只准单向引用）

```
b3 变量（思源主题） → --lvct-* 语义令牌（_tokens.scss） → .lvct-* 组件类
```

- **组件 SCSS 只准消费 `var(--lvct-*)`**；禁止 hex/rgba 字面值、禁止直接引用 `--b3-*`。
  唯一例外是 `_tokens.scss` 自身——桥接 b3 只允许发生在这里。
- 历史代码（`src/index.scss` 现存规则）暂豁免，由 UI-01 逐步迁移；**新增代码不豁免**。

### 3.2 快速查用

| 要做什么 | 用什么 |
|---|---|
| 卡片/面板底 | `var(--lvct-bg-surface)`，浮层用 `--lvct-bg-elevated` |
| 正文/辅助/占位文字 | `--lvct-text-1 / -2 / -3` |
| 描边 / 悬停描边 | `--lvct-border-subtle / -strong` |
| 主按钮 | `background: var(--lvct-brand-gradient)`（品牌渐变，每屏最多 1 个） |
| 选中/强调浅底 | `var(--lvct-accent-soft)` |
| 生日/提醒橙 | `--lvct-highlight(-soft)`；成功/危险/信息同理 `-soft` 后缀 |
| 分组色（五色） | `--lvct-group-family/-friend/-work/-school/-other`（均有 `-soft` 变体） |
| 头像 | 尺寸 `--lvct-avatar-sm/md/lg`；渐变 = 分组色 → `color-mix(分组色 60%, black 10%)` |
| 间距 | `--lvct-sp-1..6`（4/8/12/16/24/36px） |
| 圆角 | `--lvct-r-sm/md/lg/xl/pill` |
| 阴影 | `--lvct-shadow-1/2/3`（静止/悬停/浮层） |
| 过渡 | `transition: all var(--lvct-dur-fast) var(--lvct-ease)` |
| z-index | `--lvct-z-peek/dialog/popover/toast` |
| 布局 | `--lvct-sidebar-w / --lvct-peek-w / --lvct-dialog-w(-wide)` |

完整令牌语义见 `_tokens.scss` 逐行注释；视觉对照见原型「色彩与令牌 / 字体·间距·动效 / 组件规范」三页。

### 3.3 规则细节

- **明暗主题**：表面/文字/主色走 b3 变量，思源切主题自动适配，**不要写 dark 覆写**；
  只有阴影、分组色、点缀橙有明暗双配方，且只允许在 `_tokens.scss` 末尾的
  `html[data-theme-mode="dark"]` 覆写块中维护。
- **b3 fallback**：引用 b3 变量必须带兜底（`var(--b3-theme-success, #23b27c)`），
  b3 变量随思源版本有增删（先例见 DATA-CONTRACT §6）。
- **新增令牌**：先在 `_tokens.scss` 登记（注明用途与 b3 映射），再使用；组件里不得临时造变量。
- **挂根**：令牌只挂在 `.lvct-tab-root, .lvct-dialog-root, .lvct-doc-strip` 上，不污染全局 `:root`；
  新增插件根容器时同步追加到两处选择器。
- **color-mix()** 要求 Chromium ≥111，思源 3.8.x（Electron 新版）满足；若需支持更老内核再降级。

## 5. 关键设计决策（速查；完整论述见原型「总览」页）

1. **左侧栏导航取代顶部三 Tab**：对齐 Notion/Obsidian，为二期「组织/建议」留位；设置从侧栏底部进。
2. **详情改右侧 Peek（400px，无遮罩）**：不挡列表、可翻阅多人；点击外部不关闭防误丢输入。
3. **统一主操作 = 打开 Peek**：卡片/表格点击行为一致；「打开文档」收敛为悬停图标钮（修复现状行为分裂）。
4. **详情内常驻编辑/删除入口**：修复现状"编辑藏在文档档案条"的发现性问题；删除先解绑行（契约 §1.3）。
5. **捕获改三步向导**：识别（双链=确定 / AI=提名，徽标分层）→ 确认场合 → 完成；AI 只提名不决定。
6. **设置页六分区**：通用/数据与字段/提醒/AI 与隐私/服务桥/关于；含字段健康检查（落实 D-0006 降级重建）。
7. **分组色令牌化 + 明暗双套**：替代现状硬编码 hex；头像渐变由 color-mix 派生。
8. **浮层四级 L0–L3**：内容 < Peek(z-20) < 模态(z-100) < 下拉/Toast(z-200/300)；模态统一 ESC + 焦点陷阱。
9. **空态给 1–3 个下一步；加载一律骨架屏**；成功 Toast 4s 附动作，失败 Toast 常驻。
10. **移动端**：全屏 Dialog + 底部 Tab Bar + Peek 变底部抽屉；判定用 `getFrontend()`（铁律 8）。

## 6. 开发约束（AGENTS.md 铁律摘编，违反会被测试拦）

- 分层单向依赖：`components/ → (types, services, domain, data, api)`；`domain/` 纯函数禁 import svelte/api。
- 内核交互只准在 `src/api/`；itemID ≠ 文档 ID，换算只经 `api/av.ts#mapBoundDocIds`。
- 插件自管 JSON 一律经 `data/storage.ts`；**存储/偏好键变更先改 DATA-CONTRACT 再改代码**。
- 颜色一律 b3 变量（现经 `--lvct-*` 间接消费），类名前缀 `lvct-`，不硬编码色值。
- 移动端判定用 `getFrontend()`，禁 UA 嗅探。
- UI 文案当前中文硬编码（D-0004/D-0010）：新增文案直接中文，M5 由 parity 测试兜底补键，不要自行引入 i18n 框架。

## 7. 验证流程（每个任务完工必跑）

```bash
pnpm check          # tsc + svelte-check
pnpm test           # 域层单测 + 架构守门 + i18n parity
pnpm test:ui        # 隔离 Chromium 中运行真实组件，内核/存储使用内存替身
pnpm build          # 产物可构建
pnpm check:release  # 构建后的发布产物门禁
```

浏览器回归的运行条件、覆盖范围及局限见 `docs/UI-REGRESSION.md`；它不等于真实思源内核或真机验收。

人工核对：明暗主题切换无刺眼/反色异常；键盘-only 走通所改流程；移动端（若涉及）用真机或
`getFrontend()` mock 验证。视觉基准 = `docs/ui-prototype.html` 对应帧。

## 9. 已知风险与开放问题

1. **b3 变量版本漂移**：个别变量在新版思源可能更名/废弃 → 已全部带 fallback；若发现失效变量，
   修 `_tokens.scss` 一处即可，不要散改组件。
2. **用户自定义主题**：第三方主题可能重定义 b3 变量导致观感偏差 → 这是"原生感"原则的预期代价，
   不做插件级强行校正；分组色为自有令牌不受此影响。
3. **Peek 与思源 dock 的取舍**：详情放插件内 Peek（本方案）还是思源右侧 dock 曾有两种声音；
   定稿选插件内 Peek（图谱/仪表盘内同样可用，dock 只在编辑器场景可达）。若未来要支持 dock，
   Peek 组件按 props 复用即可，布局不返工。
4. **批量操作（UI-04）的写放大**：批量改分组/标签须复用名册缓存失效与 200/批约定（契约 §4），
   禁止逐行同步 await 循环。
