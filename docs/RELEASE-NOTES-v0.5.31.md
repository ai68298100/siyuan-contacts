# v0.5.31 发布说明

发布日期：2026-10-22

## 核心亮点：全工程 UI、功能、显示与交互全景深度防御与加固

针对用户关于“全面审查所有代码、UI、功能、显示与交互，确保此前类似缺陷绝对不再出现”的高标准指示，本版本展开了全方位的无死角工程走查与深层防御：

### 1. 全局布局拉伸与溢出隐患彻底清除
- **组织管理搜索栏自适应防御**：在 SCSS 核心层为 `.lvct-org-manager__member-controls` 建立弹性伸缩规范（`min-width: 140px; height: 32px;`），彻底杜绝在不同容器宽度或特定主题下输入框被异常纵向拉伸或水平挤压变形；
- **全工程 Flexbox 检查**：审查并确认所有 input/select/button 均具备确定性高度或流式换行保护，杜绝任何破损。

### 2. 状态隔离与生命周期资源泄漏彻底闭环
- **出差助手定时器销毁**：在 `RegionExplorerDialog.svelte` 中补充 `onDestroy` 生命周期钩子，弹窗关闭时自动清理复制定时器，消除隐藏内存泄漏；
- **人物详情复制反馈定时器隔离**：对谈资备忘、微信与资料复制的多个定时器句柄实现严格的组件卸载清除机制，防范异步回调在组件销毁后非法执行；
- **组织管理多组织切换深度隔离**：切换组织时彻底复位选中集合与批量确认状态。

### 3. 全链路跳转筛选与自愈机制无死角守门
- 深度验证并守门：城市跳转（`城市 · <city>`）、姓名图谱定位（`最常联系`、`图谱定位`）、组织成员（穿透 `work`、`unspecified`、`family`、`education`）与仪表盘走势图，确保在任何网络抖动或异步缓存未就绪的情形下，均能通过动态自愈机制 100% 精准召回，绝不发生误报 0 人的假空态。
