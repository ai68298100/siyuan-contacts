# 组织页面原型与规划

## 页面原型

```text
组织
┌──────────────────────────────────────────────────────────────┐
│ 搜索组织     状态：全部       重新加载   组织管理  ＋新建组织 │
├──────────────────────────────────────────────────────────────┤
│ [Logo] 远山科技   远山       12 名成员                         │
│       记录组织定位、合作背景……              管理  编辑资料     │
│                                                              │
│ [⌂] 家庭         4 名成员                  管理  编辑资料     │
└──────────────────────────────────────────────────────────────┘
```

点击“新建组织”进入独立资料页：

```text
新建组织
┌──────────────────────────────────────────────────────────────┐
│ 选择起点：家庭｜小学｜初中｜高中｜大学｜工作单位｜社区/社团   │
├──────────────────────────────────────────────────────────────┤
│ 基本资料       组织名称 *｜简称｜企查查链接｜介绍              │
│ Logo            上传图片｜Logo 链接｜预览｜移除                 │
│ 部门设置       部门名称｜上级部门｜部门介绍｜添加部门           │
│ 自定义内容     字段名｜字段值｜添加字段                         │
├──────────────────────────────────────────────────────────────┤
│                                     取消       保存组织资料     │
└──────────────────────────────────────────────────────────────┘
```

名称是唯一必填项。企查查链接、Logo、部门父子关系和自定义字段在保存前校验；保存后资料写入 `organization-profiles.json`，组织文档标题和成员关系继续由原有组织事实源维护。

## 已落地的联动

- 组织页工具栏、空状态和组织管理页均可打开新建资料页。
- 联系人详情、联系人编辑页在没有合适组织时显示“新建组织”，创建后可继续登记归属。
- 组织卡片展示 Logo、简称和介绍；卡片可直接编辑资料。
- 编辑资料会回填当前组织信息；名称变更同时走既有组织改名流程。
- 新工作空间初始化时幂等创建“家庭”；小学、初中、高中、大学、工作单位、社区/社团作为可修改模板。
- 组织资料纳入迁移包，恢复只接受可达的稳定组织文档 ID，不按同名组织猜测映射。

## 后续规划

1. **部门与成员联动**：成员登记时从当前组织部门树选择部门，保留手工输入作为兼容兜底；部门改名按部门稳定 ID更新成员显示。
2. **组织详情页**：增加组织介绍、Logo、企查查链接、自定义字段、部门树和成员分组的只读总览，并保留成员维护入口。
3. **组织级设置**：提供默认成员分类、归档策略、是否在图谱显示组织节点、组织卡片默认排序等设置，并接入现有视图偏好。
4. **资料完整度**：在组织页提示缺少 Logo、简称、介绍或部门配置的组织，支持逐项补齐，不把缺资料误报为组织不存在。
5. **外部信息刷新**：企查查链接只作为人工回查入口；若以后接入外部服务，必须经过设置开关、请求预览和明确确认，不在打开组织页时静默联网。

## 同类产品启发

- HubSpot 将公司作为独立记录，基本属性和自定义属性并列，适合本插件的“基本资料 + 自定义内容”分层。
- Airtable 用关联记录表达部门、成员和组织单元，适合保留稳定 ID、避免按名称猜测归属。
- Notion 的 People Directory 与团队空间强调人员目录、团队结构和组织知识入口，适合后续补组织介绍、部门树和组织 Wiki。

本插件当前先把组织资料和成员事实分开：组织文档/成员 JSON 负责身份与关系，组织资料 JSON 负责可编辑描述。这样既能丰富 UI，又不会把 Logo、介绍等描述字段混进成员关系事实。
