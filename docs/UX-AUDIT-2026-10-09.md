| 最近互动筛选 | 互动读取失败时可能把空结果误判为“从未联系” | 暂停日期/从未联系条件和最近互动排序，明确提示并保留重试入口 |
| 保存视图 | 资料完整度筛选未纳入视图规则 | 保存、应用和旧数据兼容归一化均保留 `profileGap` |
| 快速填充 | 复制模板失败无反馈；已有农历生日快照缺少历法标记 | 显示复制失败原因，并在识别已有联系人时传递 `isLunar` |
| 编辑联系人 | 非法邮箱/生日要等到服务层才反馈 | 提交前复用 `validateDraft`，错误留在编辑页并阻止写入 |
| 组织成员候选 | 联系人名册失败时选择器空白，容易误认为没有联系人 | 显示名册读取失败/读取中，提供重试并锁定相关选择控件 |
| 组织资料创建 | 新建联系人/详情中创建组织后候选不刷新，重复点击可并发 | 等待资料弹窗完成后刷新候选，增加创建中状态和错误保留 |
| 组织资料编辑 | 缺少保存接口时误走创建分支，可能重复创建同名组织 | 明确提示当前环境不支持编辑并停留在编辑页 |
| 关系摘要跟进 | 跟进读取失败只能看到失败文字，无法在当前摘要恢复 | 增加“重试跟进”按钮，直接复用原读取流程 |
| 组织分页空态 | 后续分页失败且筛选无结果时误显示“没有匹配的组织” | 显示“组织列表读取未完成”，支持继续读取剩余分页 |
| 联系人选择器 | 别名索引读取期间同时显示空结果，容易误判为没有联系人 | 别名仍在加载时隐藏空结果文案 |
| 编辑页组织创建 | 异步新建组织期间关闭编辑页可能留下迟到回写 | 创建中锁定关闭守卫，完成后刷新候选并保留失败信息 |
| 识别资料编辑 | 外部识别资料进入编辑页后，新建组织未等待完成就刷新候选 | 组织弹窗保存或取消均回调收口，编辑页等待完成后再刷新候选 |
| 组织 Logo 编辑 | 清除或连续选择 Logo 时旧的 FileReader 可能迟到覆盖；保存异常可能离开编辑器 | 增加读取代际失效保护，保存异常留在编辑器并显示错误 |
| 关系图偏好 | 数据源、引用范围或中心保存失败只显示错误，用户意图容易丢失 | 保留待保存 patch，提供“重试保存”，跨窗口成功同步后自动清理 |
| 共同背景 | 空态与读取中状态无法区分 | 读取期间显示短暂加载提示，成功空列表继续保持空态不渲染区块 |
| 关闭与忙态 | 本轮复核所有主要弹窗均使用统一关闭守卫 | 保留草稿确认、忙碌阻断和宿主 X/Esc 路由 |

## 已核实正常的关键行为

- 公历与农历生日按各自历法计算下一次发生日，显示明确标注，混合排序按对应公历发生日进行。
- 批量联系人操作固定目标快照，筛选外联系人需要显式确认；部分字段失败可按稳定 ID 重试。
- 组织成员分页、搜索、状态筛选、编辑、离职、接替、归档和恢复保持稳定 ID，不以姓名自动替换。
- 互动、跟进、模板、联系节奏、别名、往来账本和关系投影的读取失败均不会伪装成空数据，并保留重试路径。
- vCard 导入的同名冲突、字段映射、农历标记、未知写入结果和重复导入均保留人工核对边界。
- 桌面和移动端按钮文案、键盘焦点、空态、加载态、错误态和弹窗关闭行为已通过隔离 UI 回归。
