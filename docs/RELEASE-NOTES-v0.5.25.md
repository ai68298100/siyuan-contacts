# v0.5.25 发布说明

发布日期：2026-10-21

## 核心亮点：深度汲取优秀设计美学——Bento Grid、周度时序滑轨、气泡时间线与轻奢英雄卡全面落地

本版本全面吸收并落地了高颜值现代生产力工具的 6 大核心 UI/UX 设计灵感，让小驴人脉在严谨架构的基础上，展现出充满生命力与人情味的界面美感：

### 1. Bento Grid 便当盒微色调指标卡体系
- 首页 4 大核心指标卡全面告别单调纯白，引入低饱和度雅致渐变微色调：
  - **联系人**：柔和清爽的浅天蓝/冰蓝微渐变；
  - **关系网络**：优雅知性的浅丁香紫微渐变；
  - **本周生日**：温暖生动的浅杏金暖色微渐变；
  - **待激活/从未互动**：柔和提醒的浅珊瑚粉微渐变；
- 每张卡片右上角配备精致的胶囊角标（`全库`、`互联`、`本周`、`待激活`），空间层次感与层级节奏瞬间鲜明。

### 2. 首页正向关怀里程碑横幅（Milestone Encouragement Banner）
- 仪表盘上方新增充满鼓励感的关怀里程碑横幅，庆祝人脉连接成果（如：`🌟 人脉连接状态极佳！已建立连接 X 人，覆盖率 Y%`）；
- 消除任务式维护好友的焦虑感，赋予持续记录的正向情感反馈。

### 3. 周度 7 天时序日程滑轨（Weekly Glance Strip）
- 今日行动模块上方常驻「📅 本周日程视窗」滑轨；
- 以横向胶囊清晰呈现今天及未来 6 天的日程，高亮标记今日（`今天`）；
- 动态标注哪天有好友过生日（🎂）或待办跟进（📌），点击任一天可即时聚焦当日安排，掌控感大幅提升。

### 4. 连接线气泡式互动时间线（Connected Bubble Timeline）
- 人物详情页互动时间线全面重塑为现代气泡对话卡片质感（`border-radius: 12px`、柔光微阴影与独立边框）；
- 左侧贯穿发光时间轴线节点，类型标签、时间徽章、记录正文与操作区分区明确、呼吸感十足。

### 5. 人物详情页轻奢质感英雄卡（VIP Profile Hero Card）
- 针对星标常用好友（⭐），详情页顶部英雄卡切换为极富质感的微暖金光晕卡面与流光微发丝边框；
- 头像徽标点缀金色星标；
- 个人标签栏支持图标化人脉勋章胶囊（`⭐ 核心星标`、`🔥 温热常联系`），身份与情感连接度跃升。
