# v0.5.33 发布说明

发布日期：2026-10-22

## 核心亮点：组织 Master-Detail 双层看板、全插件 Select 居中对齐、详情页排版大重塑与互动正文同步引擎

本版本针对用户实测反馈提出的 5 项核心诉求展开了深度重构与架构升级：

### 1. 修复全插件 Select 下拉框文本水平与垂直居中
- 锁定 `.b3-select` 的高度与行高，修正内边距与对齐基线，强制应用 `text-align: center; text-align-last: center;`；
- 彻底解决名册中「全部分组」与「按姓名」偏顶偏左、对齐失准的历史遗留缺陷，全工程下拉框呈现完美居中排版。

### 2. 组织页面下半区重塑：消除大白框，实现 Master-Detail 架构看板
- 彻底消除组织卡片下方大面积空白荒漠，升级为现代双层 CRM 看板；
- 点击任意组织卡片，下半区立即展开**「选定组织架构与成员全貌」**（显示组织简介、部门分布胶囊、成员在职/历史卡片一览与极速筛选直达）。

### 3. 人物详情页大重构：扩至 920px、清除生硬技术 ID
- 弹窗宽度扩展至宽阔舒适的 `920px`，彻底终结纵向逼仄拥挤感；
- 移除生硬的技术调试字符串（`本人文档 2026...`、`核对时间...`、`历史与待核对 0 条`）；
- 档案资料升级为规整优雅的卡片栅格网格。

### 4. 落地「人脉文档正文同步引擎」与笔记正文文本提及识别深度融合
- **互动真实落盘**：记录或删除互动时，自动以带 `custom-lvct-interactions` 属性的原子块同步落盘至该联系人的思源笔记正文（`## 往来记录`），思源全局搜索可搜、导出可带、离线可用；
- **笔记正文文本提及识别升级**：从笔记捕获人脉时，除了显式双链，自动嗅探正文中出现的联系人名字（未打双链的虚拟引用），支持一键全员沉淀互动并双向落盘至各自的人物独立文档中。
