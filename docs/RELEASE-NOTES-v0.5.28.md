# v0.5.28 发布说明

发布日期：2026-10-22

## 核心亮点：全流程深入排查与体验加固——周度日程一键直达、全量重置闭环与组织隔离防泄漏

本版本开展了深入细致的全流程排查走查，针对各界面功能细节、状态隔离与操作闭环进行了深度打磨：

### 1. 首页「本周日程视窗」全交互升级
- 聚焦当日安排时，生日好友（🎂）与待办事项（📌）全面升级为可交互的一键直达按钮；
- 点击任一当日生日或待办，直接精准调起对应好友的详情面板，实现日程到人脉资料的极速闭环。

### 2. 名册「清除所有筛选」状态彻底归位
- 在触发「清除所有筛选」时，完整重置包括拼音首字母过滤（A-Z）与星标常用过滤在内的所有附加状态；
- 保证用户在任何复合筛选状态下点击清除，均可一秒恢复至清爽的原始全量名册。

### 3. 组织管理多组织切换状态严格隔离
- 组织管理弹窗（`OrgManagerDialog`）在左侧切换不同组织时，严格自动清空选中成员（`selectedMemberIds`）与批量删除确认状态；
- 彻底避免在组织 A 中勾选的成员 ID 泄漏至组织 B 中导致误操作。
