# v0.5.41 发布说明

发布日期：2026-10-23

## 核心亮点：多行备注防裂行防御与 IAL 属性跨行解析加固

本版本聚焦于 Markdown 原生结构健壮性与思源底层原子块属性比对的边界加固，解决在特殊输入和长文本下的潜在结构破坏问题：

### 1. 多行备注与说明防裂行防御 (`cleanMarkdownLine`)
- **根除列表项撕裂 Bug**：当用户在互动记录、人情往来账目说明、或待办跟进标题中输入多行回车文本时，以往直接拼接会导致 Markdown 列表项破裂为游离段落；
- **优雅内联折行**：引入 `cleanMarkdownLine` 纯函数过滤引擎，将多行回车安全转换为 `<br />`，不仅 100% 保持单行列表语法的严谨性，还能在思源笔记正文中忠实保留用户的换行排版意图。

### 2. 块属性 IAL 跨行精准比对与假脏态免疫
- 升级 `contentWithoutIal` 属性清洗引擎，支持多属性跨行 IAL 语法的无残留剥离；
- 彻底消除因为思源底层属性回读格式差异导致的“假脏态”与多余重写，全面提升正文同步的幂等稳定性。
