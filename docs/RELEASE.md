内核测试执行前验证回环端口空闲、工作区标记 JSON 与创建者匹配，拒绝未标记/损坏标记、项目或宽泛目录；数据与插件安装目标不得通过链接越出工作区。每次请求前后检查本次内核进程仍存活，请求超时为 5 秒。启动未确认或进程已退出时不向端口发送退出请求，仅处理本次子进程。端口预检不是持续保留端口，仍应避免同时启动其他服务抢占测试端口。
