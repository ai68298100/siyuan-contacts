# v0.5.44 发布说明

发布日期：2026-10-24

## 核心亮点：双模反链感知（显式双链 + 正文提及）、英雄卡反链徽章与纯净文本清洗

本版本进一步深化了思源笔记知识网状链接与人脉系统的深度融合体验：

### 1. 双模反向引用感知引擎 (`kind: "link" | "mention"`)
- **正文纯文本提及自动嗅探**：升级 `findPersonBacklinks`，除通过 `refs` 索引检索显式双链外，自动扫描知识库正文中出现联系人姓名的纯文本提及（Mentions，虚拟引用）；
- **清晰分类标识**：反链视窗清晰区分 `🔗 双链`（带括号的块引）与 `💡 提及`（正文直呼其名），支持一键定位原笔记或一键转录为互动。

### 2. 英雄卡反链引用直达徽章
- 在人物详情顶部英雄卡中，新增 `🔗 n 条反链引用` 交互胶囊；
- 一眼获知该好友在整个知识库中的活跃与提及频次，点击秒级平滑定位到“互动”Tab 反链视窗。

### 3. 双链文本语法清洗与排版优化 (`cleanBlockRefText`)
- 自动将 `((id "姓名"))` 清洗为自然流畅的纯净文本，彻底消除段落引用中生硬的代码括号与技术 ID。
