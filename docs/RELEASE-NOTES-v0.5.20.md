# v0.5.20 发布说明

发布日期：2026-10-21

## 核心亮点：深度双向联动图表、出差规划、Issue #35 攻坚与人物详情/名册体验全面重塑

本版本是一次聚焦于**“数据互联、场景下钻与交互质感”**的重大版本更新，彻底打通了首页仪表盘、关系图谱、联系人名册与人物详情之间的信息孤岛，解决了长期遗留的特定手机通讯录导入痛点，并大幅优化了高密度名册检索与整理体验。

### 1. 深度双向联动图表体系（Dashboard & Graph）
- **首页人脉温度与紧迫度交互图表（Heat Chart）**：
  - 基于客观互动时间与联系周期，全库 0 额外网络开销推导 6 级人脉温度（🔥温热、🌿常温、🍂微凉、❄️渐冻、⚪未互动、⏸️已暂停）；
  - 精美多段比例条与状态胶囊，点击任意分段即时联动跳转名册筛选对应人群。
- **首页近半年互动活跃走势微图表（Activity Trend Chart）**：
  - 自动聚合最近 6 个月的月度互动频次与人脉活跃走势，点击任一月份柱子直达名册查看该月互动的全部联系人。
- **城市人脉分布与出差规划（RegionExplorer）**：
  - 仪表盘展示核心城市分布胶囊，点击任一城市直接联动在名册中精准过滤；
  - 附带出差规划弹窗，支持按城市探索人脉、同省周边关联推荐，并一键生成出差拜访 Markdown 清单。
- **图谱双向闭环与「图例即过滤器」**：
  - 图谱右上角图例升级为即时过滤器，点击分组（家人/同事/朋友/组织）瞬时切换网络显隐；
  - 常驻一度/二度关系层级切换胶囊，快速拓展二度人脉引荐；
  - 名册与详情页新增「图谱聚焦」入口，名册多选支持一键在图谱中比对网络；图谱反向提供「在名册中定位」与「在名册中比对二人」。

### 2. 攻坚 Issue #35：二阶段渐进式兜底挽救机制
- 针对小米等安卓设备导出 VCF 时第一张卡片或特定联系人缺少 `FN`/`N` 属性导致全包解析被拒崩溃的问题，实现二阶段自动挽救；
- 允许以主要电话或邮箱智能暂代命名（如 `未命名 (13800138000)`），完整保留号码并透明提示用户核对，彻底消除了导入阻断。

### 3. 人物详情页（PersonDetail）体验与思源互动深度重构
- **信息架构清晰梳理**：概览与互动职责解耦，概览专注于静态核心档案，互动 Tab 汇集联系节奏、待办跟进、记一笔互动与完整时间线；
- **思源笔记深度互动**：
  - 一键复制思源标准双链/块引用 `((docId "姓名"))`，直接粘贴到笔记正文中引用人物；
  - 快捷直通打开人物独立笔记文档；
  - 会前面谈简报 Markdown 全文一键复制与即时反馈；
  - 头部智能识别并展示所在城市徽标与「同城人脉」下钻。

### 4. 联系人名册（PeopleView）查阅与整理质感升级
- **A-Z 拼音首字母跳跃索引条**：一键按首字母过滤大名册，极大提升几百人时的查找速度；
- **常用分组快捷切换胶囊**：全部、家人、同事、朋友等带人数 Badge 即时切换；
- **卡片去噪与舒适/紧凑（Compact）双视图**：彻底消除“生日未填写”、“暂无互动”等空白占位，紧凑模式一屏容纳 20+ 人；
- **极速建档闭环**：支持键盘 `/` 键速搜、`Esc` 清空，搜索无结果时提供「一键以此名新建联系人」自动预填。
