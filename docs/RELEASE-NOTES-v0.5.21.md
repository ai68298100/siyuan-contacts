# v0.5.21 发布说明

发布日期：2026-10-21

## 核心亮点：全页面 UI 深度统一与重塑，终结空间浪费与信息碎片化

本版本针对用户在真实日常使用中反馈的**“首页图表视觉突兀、联系人顶部工具栏碎片化拥挤、卡片信息截断、组织页面下半区大片空白”**等核心痛点，进行了深度 UI/UX 重构与统一规范打磨：

### 1. 首页仪表盘人脉洞察全景重塑
- **对齐指标卡视觉风格**：重塑人脉温度分布、近半年互动走势与核心城市图表，采用与上方统计卡一致的卡片圆角、细边框与柔和微阴影；
- **三栏等高紧凑布局**：自适应三列等高排版，消除此前城市卡片空白过大、走势图立柱矮短与上下大片空白的问题，视觉节奏高度和谐。

### 2. 联系人名册（PeopleView）工具栏与排版重塑
- **消除破碎换行，双行清晰两段式工具台**：
  - 第一行聚焦【搜索与核心业务动作】：全宽输入框（集成 `/` 速搜与 `Esc` 清空）+ 突出绿色的「新建联系人」+ 紧凑辅助操作栏，彻底解决原先 5 个低频按钮掉在右下角悬空的尴尬；
  - 第二行聚焦【视图与筛选控制】：视图预设、分组、排序、更多筛选 + 舒适/紧凑切换 + 卡片/表格切换；
- **轻量级分组与拼音首字母 A-Z 跳跃条**：
  - 分组切换与字母跳转条采用轻盈无框内联设计，高度大幅压缩，绝不挤占垂直空间。

### 3. 卡片去噪与彻底消除截断
- **解除固定宽度写死截断**：彻底移除以往写死的 180px 宽度限制，组织名称自适应卡片宽度，超长单位名称优雅展示并支持完整 title 悬停查看；
- **关系称谓与组织分类优雅分离**：岳母、大舅妈等称谓呈现为独立的精致小药丸徽章，避免被长单位名称挤到下一行断裂。

### 4. 组织工作台（OrgsView）彻底消除下半区空白
- **新增组织全景数据洞察条（Orgs Overview Bar）**：
  - 汇总展示活跃组织数、在职/在学人脉数、历史经历数与归档组织数，形成组织维度驾驶舱；
- **栅格网格重塑**：
  - 自适应 340px 舒适大卡片排版，大幅提升大屏幕与宽屏下的视觉饱满度，终结大面积空白。
