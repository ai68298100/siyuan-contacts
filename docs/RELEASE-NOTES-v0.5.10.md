# 小驴人脉 v0.5.10

本次发布修复首页久未联系排版问题，并全面梳理新建、编辑与组织管理等核心页面的文字与表单选项合理性。

修复：久未联系文字挤压与排版优化

- 彻底根治久未联系卡片因未填资料在 flex 布局下被极端挤压导致单字垂直竖排的问题；紧凑资料摘要增加强制单行防换行与平滑省略保护。
- 首页久未联系与近期生日列表重构为“主信息层 + 状态/行动层”现代双层卡片排版，增加 32px Squircle 柔光渐变微头像，按五大人脉分组呈现温润色彩。

优化：新建、编辑与组织管理页面表单与文案

- 将新建联系人与资料编辑弹窗底部的核心保存按钮由文字样式升级为具备微阴影与顶切高光的实色主按钮，突出主操作视觉层级。
- 优化表单底部提示文案，消除“绑定为数据库一行”等生硬内部技术术语，改为自然通俗的产品化表达。
- 统一组织归属分类下拉选项为更贴合高频输入直觉的顺序（工作单位、学校、家庭、其他组织），并优化扩展资料单独保存按钮文案。

## 安装

从 [GitHub Release v0.5.10](https://github.com/ai68298100/siyuan-contacts/releases/tag/v0.5.10) 下载 `package.zip`，解压到思源工作空间的 `data/plugins/siyuan-contacts/`，重启思源后启用插件。发布包同时提供 `package.zip.sha256`。

本版本仍不改变已知限制：真实 Android 真机、思源原生图入口、任务管理器互读、集市客户端可见性和 CardDAV 在线同步需单独验收。
