# v0.5.29 发布说明

发布日期：2026-10-22

## 核心亮点：全方位功能走查与极致顺畅打磨——原生搜清联动、快捷键极速切人与微信号一键复制

本版本以**“让人脉管理更加自然顺畅”**为核心目标，针对日常管理中的高频痛点进行了深度交互打磨：

### 1. 检索与清空极速响应（Native Search Clear）
- 桌面端与移动端搜索框全面升级为原生搜索语义，在 Chromium 内核下原生支持点击快速清空按钮（×）一秒恢复；
- 配合键盘 `/` 键速搜与 `Esc` 清空，形成“键盘流”与“鼠标流”双重丝滑闭环。

### 2. 人物详情页极速切人快捷键（Alt + ← / →）
- 在人物详情面板中，新增全局快捷键 `Alt + ←`（上一位）与 `Alt + →`（下一位）；
- 极大提升了用户在密集查阅人脉档案、回顾历史互动时的流转效率，无需频繁移动鼠标去右上角点击按钮。

### 3. 名册卡片微信号一键复制反馈
- 联系人卡片上的微信号不仅直观展示，还支持鼠标一键点击快速复制到剪贴板，并带有明确的视觉提示；
- 配合既有的电话直拨（`tel:`）与邮箱客户端调起（`mailto:`），实现了通讯方式的全链路闭环。
