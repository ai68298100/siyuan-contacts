# v0.5.24 发布说明

发布日期：2026-10-21

## 核心亮点：全页面 UI 深度走查打磨、暗色模式金属微切光适配与移动窄屏丝滑响应

本版本深入走查并打磨了全插件各个界面的微小视觉与交互瑕疵，重点提升了暗色主题下的光影质感与小屏幕/窄窗口下的自适应能力：

### 1. 全页面暗色模式（Dark Mode）深度适配与金属微切光
- 将新增的全部容器（包括组织全貌指标条、详情快捷操作条、组织成员网格小卡片、A-Z 索引条、批量管理条、仪表盘全景图表等）完整纳入暗色模式微切光体系；
- 采用统一的 `rgba(255, 255, 255, 0.08)` 发丝边框与环境漫反射，彻底消除深色背景下的生硬白色反光与对比度违和；
- 星标金色五角星（⭐）增加平滑缩放反馈动效。

### 2. 移动端与窄屏响应式体验精雕细琢
- **A-Z 拼音首字母条防折行**：加入横向滚动与触摸手势支持，在任意窄窗口下均保持单行整洁滑动，绝不被挤爆折成多排；
- **常用分组胶囊栏单行滑动**：支持单行横向顺滑滚动，兼顾桌面大屏与手机小屏；
- **组织管理成员网格卡片响应式**：在窄视口下自动单列平铺（`1fr`），操作按钮自适应收口，杜绝横向滚动条或右侧遮挡。
