# 小驴人脉 v0.5.8

本次小版本集中修复联系人导入、联系人视图切换和组织管理问题，并补充联系人批量加入组织能力。

新增：联系人批量加入组织

- 联系人多选后可批量登记到指定组织，操作前固定联系人范围。
- 读取组织列表时过滤无效项，归档组织不可选；没有组织时提供空态、新建组织和重新读取入口。
- 逐人调用现有组织成员服务，沿用成员关系的幂等和写后核实逻辑。

优化：批量操作反馈

- 读取和保存期间锁定重复提交、关闭和范围修改。
- 部分成功显示失败联系人和具体原因，重试只处理失败项，不重复调用已经成功的联系人。
- 全部完成后自动刷新名册并回到联系人列表。

修复：大批量联系人导入

- 属性视图绑定和文档 ID 映射统一按 50 条分批，避免思源端点在大请求下只处理前 50 条。
- 每批写入后回读核实，未核实结果不会被误报为成功，也不会自动盲目重发。

修复：联系人视图切换闪烁

- 卡片/表格切换保留本地视图意图，旧偏好响应不会让页面反跳。
- 已有名册刷新时保留当前列表，不再反复显示骨架屏；详情返回会等待完整刷新并恢复目标焦点。

修复：组织管理页面排版

- 添加成员区域的说明文字独占一行，选人器不再被 flex 布局压缩。
- 桌面组织管理弹窗最大宽度调整为 900px，组织资料编辑弹窗最大宽度调整为 920px；移动端继续使用全屏弹窗。

## 安装

从 [GitHub Release v0.5.8](https://github.com/ai68298100/siyuan-contacts/releases/tag/v0.5.8) 下载 `package.zip`，解压到思源工作空间的 `data/plugins/siyuan-contacts/`，重启思源后启用插件。发布包同时提供 `package.zip.sha256`。

本版本仍不改变已知限制：真实 Android 真机、思源原生图入口、任务管理器互读、集市客户端可见性和 CardDAV 在线同步需单独验收。
