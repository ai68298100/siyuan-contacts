# v0.5.32 发布说明

发布日期：2026-10-22

## 核心亮点：卡片直击速记互动、外部深度链接唤起与全局流畅度闭环

本版本围绕**“让人脉管理如行云流水般自然”**的目标，进一步打通了人脉卡片到互动记录的极速通路，并扩展了思源人脉与外部操作系统软件的双向连接能力：

### 1. 联系人卡片直击「速记互动」（Quick Interaction Launcher）
- 在名册舒适卡片与紧凑卡片的操作区中，新增「记互动」快捷图标（`MessageSquarePlus`）；
- 鼠标一键点击，瞬间调起人物详情页并**直达「互动」Tab**，自动聚焦备注输入框；
- 用户在浏览名册时，无需经历“点详情 -> 等待 -> 找互动 Tab -> 滚动到输入框”等繁琐步骤，两秒内即可完成一次日常拜访或微信交流的记录闭环。

### 2. 详情页支持一键复制「思源深度链接」（siyuan://blocks/docId）
- 快捷操作栏新增「复制深度链接」按钮；
- 复制出的 `siyuan://blocks/<docId>` 支持在任何外部软件（如微信、飞书、邮件、日历、待办清单或网页）中直接点击，**一键唤起思源笔记并直达该联系人独立文档**；
- 让人脉网络无缝融入用户的日常跨应用工作流。
