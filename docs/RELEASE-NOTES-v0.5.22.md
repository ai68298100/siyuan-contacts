# v0.5.22 发布说明

发布日期：2026-10-21

## 核心亮点：组织管理弹窗（OrgManagerDialog）全面重塑——小卡片网格形态与批量多选管理体系

针对用户在组织管理实测中反馈的**“一长串单列堆叠不方便管理、缺乏小卡片形式与多选能力”**的核心痛点，本版本对组织管理弹窗进行了全方位的结构重构与交互升级：

### 1. 成员小卡片网格化重塑（Member Card Grid）
- **网格小卡片模式（默认）**：
  - 彻底告别一长串单调纵向堆叠，转为自适应双列/三列微型卡片网格（`minmax(260px, 1fr)`）；
  - 每张卡片整合了**首字母柔光微渐变头像**、**加粗姓名**、**在职/离开状态药丸徽章**、**部门与职位**、**任职期间**与操作栏；
  - 视野开阔、信息密度适中，卡片悬停微浮动，选中高亮反馈清晰。
- **支持卡片/列表模式自由切换（View Mode Toggle）**：
  - 工具栏提供「卡片」与「列表」切换胶囊，满足不同查阅偏好。

### 2. 多选与强大批量管理体系（Batch Management）
- **复选框与全选本页**：
  - 无论在卡片模式还是列表模式下，每个成员项均自带复选框，头部支持一键「全选本页」；
- **批量浮动控制台（Batch Bar）**：
  - 勾选成员后动态浮出批量操作栏：
    - **批量设为在职**：一键将选中的成员状态批量更新为当前在职/在读；
    - **批量设为离开**：一键将选中的多位成员状态变更为已离开，自动记入离开日期；
    - **复制 TSV**：一键将选中成员的结构化表格数据复制到剪贴板；
    - **批量移除**：带有安全确认保护，批量解除选中成员在当前组织的经历记录；
  - 批量操作期间严格防重复提交与锁内并发保护，写后自动原地刷新。
