# v0.5.34 发布说明

发布日期：2026-10-23

## 核心亮点：Excel/CSV 标准通讯录模版导入向导与人脉档案正文全量同步闭环

针对用户提出的“每个人脉在插件中填写的所有的信息，都应该在文档中有体现，包括姓名、电话等基本信息，互动信息，各种其他信息，都应该在文档中有留存”以及“是否可以模版（Excel）导入”的关键指示，本版本落地了全套解决方案：

### 1. Excel / CSV 标准通讯录模版导入向导
- **下载标准模版**：在导入面板中新增「下载 Excel/CSV 导入模板」直达按钮，一键导出自带 UTF-8 BOM（Microsoft Excel 双击打开绝不乱码）的《小驴人脉通讯录导入模板.csv》；
- **智能列名映射**：内建纯函数 RFC 4180 高性能解析引擎（`csv-contacts.ts`），自动识别中英文别名表头（姓名、电话、微信、邮箱、生日、是否农历、分组、标签、公司、部门、职位、备注）；
- **全流程安全复用**：无缝接入既有的批量查重、重名检测、挑选确认、批量写入与逐项报告安全队列，支持几十到数百人一键导入。

### 2. 人脉基本档案与往来全量正文同步（文档即档案）
- **基本档案正文沉淀**：在 `doc-section.ts` 中建立 `PROFILE_SECTION_ATTR`（`custom-lvct-profile`）区块，将联系人的电话、微信、邮箱、生日、分组、标签、单位/职务、与我的关系等全量信息以优雅规范的 Markdown 列表形式真实落盘到独立笔记正文中（`## 人脉基本档案`）；
- **详情页一键「同步档案到正文」**：人物详情快捷工具栏新增专属同步按钮，点击即可将最新档案与往来记录一次性完整写入思源正文；
- **编辑保存自动联动**：在编辑资料保存后自动触发增量同步，彻底消除“插件数据与思源笔记脱节”的割裂感；
- **思源原生能力完全激活**：思源全局搜索可搜、移动端直读、导出 PDF/Markdown 档案完整随行。
