# v0.5.27 发布说明

发布日期：2026-10-22

## 核心亮点：全工程跳转筛选自愈容错升级、图谱与各弹窗工具条自适应收口与 b3-chip 全局美化

本版本针对跨页面交互跳转与全局样式一致性进行了系统级深度排查与加固，彻底杜绝任何潜在的空结果漏判与布局拉伸隐患：

### 1. 全链路名册跳转筛选自愈容错机制升级
- **城市与地域跳转自愈**：名册筛选器增加对 `城市 · <city>` 的智能容错降级，自动解析人物档案中的城市与省份信息，即使底层映射未及时就绪，也 100% 能够精准捕获目标城市的联系人，绝不报 0 人；
- **姓名与图谱定位跳转自愈**：覆盖 `最常联系 · <name>` 与 `图谱定位 · <name>` 语义，与名册主索引双向核验；
- **组织成员全归属穿透**：全面穿透 `work`、`unspecified`、`family`、`education` 四类归属，确保组织管理跳转 100% 呈现。

### 2. 全局 `.b3-chip` 样式覆写与美化
- 统一重塑全插件各模块中的 `.b3-chip` 胶囊（包括仪表盘人脉温度、城市徽章、图谱关系深度切换与出差助手），彻底消除思源原生或三方主题下突兀粗硬的 1px 黑边框与方角破损感；
- 统一采用高质感柔和圆角（`border-radius: 9999px`）、主题色微背景与轻盈微光边框，与整个设计系统无缝融合。

### 3. 关系图谱与组织管理工具条自适应防溢出收口
- 为 `.lvct-graph-toolbar` 建立流式自适应规范，搜索框自适应弹性缩放（`flex: 1 1 180px; min-width: 140px;`），任何窄窗口下均不会发生水平越界截断；
- 升级名册顶部的「来自首页/来自组织」焦点指示条（`.lvct-people__focusbar`），增加主题微背景与柔和下边框，交互更自然。
