# v0.5.35 发布说明

发布日期：2026-10-23

## 核心亮点：关系图谱四维布局引擎（六度人脉/族谱树）与飞书/钉钉式现代组织架构强化

本版本针对用户关于“深度调研 GitHub 族谱、关系网、六度人脉及钉钉、飞书现代组织管理并融合升级”的战略指示，落地了图谱与组织的跨越式升级：

### 1. 关系图谱四维布局引擎与六度人脉深度强化
- **四维多布局引擎**：在右下角悬浮操作簇（FAB）中新增「布局切换器」，内建四大专业图谱拓扑算法：
  - 🌐 **力导向聚类 (CoSE)**：模拟分子引力与斥力，展现自然社群聚合圈；
  - 🎯 **六度辐射圈 (Concentric)**：依据节点度数与中心人物，由内而外呈同心圆辐射分层排布，直观展现六度人脉与影响力圈层；
  - 🌳 **层级展开 (Breadthfirst / 族谱树)**：正交层次化向下递进展开，非常适合展示家族谱系、师徒传帮带与汇报链路；
  - ⭕ **全局环形 (Circle)**：圆周排布，所有跨圈与交错关系线一览无遗。
- **FAB 切换弹窗与状态持久化**：支持平滑切换与一键重新布局。

### 2. 现代组织管理升级（对标飞书/钉钉通讯录架构）
- **部门层级树状胶囊导航**：组织工作台看板新增交互式部门导航，支持在「全部」与各部门间一键穿透过滤成员；
- **管理层 / Leader 负责人智能标识**：自动识别成员职务中的“总、经理、主管、总监、主任、负责人、Leader、CEO”等关键角色，为负责人赋予高对比度专属勋章，组织管理架构一目了然；
- **标准花名册导出规范**：组织成员导出全面契合现代办公通讯录字段要求。
