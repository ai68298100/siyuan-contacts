# 小驴人脉 v0.5.11

本次补丁修复 Issue #34：从空状态点击“选择联系人”后，关系选择器会被同一次点击触发的 outside-click 监听立即关闭，导致无法继续选择联系人。

## 修复

- `PersonPicker.openPicker()` 延迟到当前点击事件完成后再打开，避免与外部点击关闭逻辑竞争。
- 增加空状态入口回归测试，覆盖关系选择器的打开时序。

## 数据与迁移

- 不新增或改变插件自管 JSON。
- 不需要迁移。
- 联系人文档、原生数据库和插件自管数据边界保持不变。
