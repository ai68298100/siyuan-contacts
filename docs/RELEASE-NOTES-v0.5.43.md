# v0.5.43 发布说明

发布日期：2026-10-24

## 核心亮点：闭环 Issue #87（笔记与日志反链直通人脉互动）、Backlinks 全景聚合与快捷转录

针对 GitHub Issue #87 用户反馈的“人物的联系相关事情是否可以改成该文档的反链，习惯在日志中记录事件”的深度笔记诉求，本版本彻底打通了思源笔记原生反向链接与人脉互动时间线：

### 1. 深度打通日记与笔记反链（Backlinks）引用视窗
- **原生反链自动汇聚**：在人物详情页“互动”Tab 中，新增「🔗 笔记与日志反链」专属折叠视窗；
- **全库日记感知**：自动检索全知识库（特别是 Daily Note / 每日日志、会议纪要等）中通过双链 `((docId "姓名"))` 引用该联系人的所有段落；
- **上下文清晰呈现**：直观展示引用发生的日期、所属笔记标题（如 `2026-10-24 工作日记`）以及具体引用段落内容。

### 2. 双向快捷联动（直通原文 & 一键转录）
- **📄 打开原笔记**：点击直接在思源中唤起该日记或随笔文档，秒级定位原上下文；
- **⚡ 转为互动**：点击一键将日记中记录的事件转录为正式互动事件，自动填充日期与备注，并同步刷新人脉最近联系时间与正文往来记录。
