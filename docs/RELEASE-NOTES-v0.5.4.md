# 小驴人脉 v0.5.4

新增：发布包校验

- 发布门禁实际计算并比对 ZIP 的 SHA-256；校验和缺失、格式错误或不匹配时停止发布。

优化：异常反馈与时间一致性

- 迁移包、交往回顾报表和导出统计严格读取数据，失败时保留错误状态，避免生成假空结果。
- 仪表盘统一时间快照，避免跨午夜时生日、久未联系和提醒截止日错位。
- 尚未开放的“建议”入口增加原因提示，修订当前状态和 12 类迁移数据说明。

修复：久未联系提醒顺延

- “顺延 3 天/1 周/1 个月”改为一次性提醒暂缓，不再永久修改联系节奏。
- 撤销可恢复原暂缓状态。

修复：数据写入与回归可靠性

- 互动、跟进、联系节奏、收编索引、提醒及块 API 严格校验 ID、日期、枚举和字段类型，阻止损坏或未知版本数据被覆盖。
- UI 回归夹具使用合法稳定文档 ID，恢复并发互动、备份合并和删除标记回归。

## 数据与迁移

未改变数据格式版本，无需自动迁移。对损坏或未知版本的插件数据，本版本会保留原值并要求核实，避免以空数据覆盖。迁移包包含 12 类插件自管数据，人物/组织文档与数据库仍须通过思源工作空间迁移。

## 安装

从 [GitHub Release v0.5.4](https://github.com/ai68298100/siyuan-contacts/releases/tag/v0.5.4) 下载 `package.zip`，解压到思源工作空间的 `data/plugins/siyuan-contacts/`，重启思源后启用插件。

## 产物校验

发布时附 `package.zip` 与 `package.zip.sha256`。下载后可通过 `Get-FileHash -Algorithm SHA256 package.zip` 或 `sha256sum package.zip` 核对。
