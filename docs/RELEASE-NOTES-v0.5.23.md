# v0.5.23 发布说明

发布日期：2026-10-21

## 核心亮点：星标常用联系人（Starred Contacts）一键置顶与全流程收藏体系（ROADMAP §2 落地）

本版本正式落地了个人 CRM 高频核心能力——**星标/常用联系人（Starred Contacts）收藏与置顶体系**，使得用户在面对庞大通讯录时，能够一秒直达最重要的核心人脉：

### 1. 名册视图一键星标收藏与常用过滤
- **卡片/列表一键点亮星标**：
  - 无论在舒适卡片还是紧凑卡片中，均呈现优雅的金色五角星按钮；
  - 鼠标一键点击即可完成星标置顶或取消，即时更新本地视图偏好并持久化，支持并发合并；
- **顶部常用星标快速切换胶囊**：
  - 当存在星标联系人时，常用分组栏最前端自动呈现 `⭐ 常用 (N)` 专属琥珀金胶囊；
  - 一键点击秒级过滤筛选出全部星标常用好友，无需输入任何关键词。

### 2. 人物详情页（PersonDetail）头部英雄卡集成
- 在人物详情页顶部的英雄卡片姓名旁，并列呈现金色星标收藏按钮；
- 用户在查阅资料、记录互动或会谈准备时，随时随地一键点亮/取消收藏，状态与名册全自动双向同步。
