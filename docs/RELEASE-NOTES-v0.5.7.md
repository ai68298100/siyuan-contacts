# 小驴人脉 v0.5.7

本次发布把前几轮真实数据链路、关系图谱、长列表性能与 UI 迭代收敛为可复用的设计系统，并同步更新原型和交付文档。

新增：统一设计令牌与组件规范

- 建立 Primitive → Semantic → Component 三层令牌，统一色彩、间距、字号、行高、圆角、阴影、层级、动效和控件尺寸。
- 按钮、输入框、复选框、单选框、加载态和键盘焦点环具备统一的尺寸与状态表现，新增页面可以直接复用。
- 新增 pnpm audit:tokens，并保留修改前后的审计 JSON 和例外说明。

优化：跨页面视觉和真实条件体验

- 浅色/暗色主题共享语义变量；关系图谱、联系人虚拟列表、错误反馈、原型与组件目录同步到当前实现。
- 保持长列表窗口化、图谱只读双链引用、统一请求/权限反馈和写后核验能力。

修复：样式状态漂移

- 修复按钮、输入框、复选框/单选框的焦点、禁用、加载反馈在不同页面不一致的问题，收敛公共样式硬编码。

## 安装

从 [GitHub Release v0.5.7](https://github.com/ai68298100/siyuan-contacts/releases/tag/v0.5.7) 下载 package.zip，解压到思源工作空间的 data/plugins/siyuan-contacts/，重启思源后启用插件。发布包同时提供 package.zip.sha256。

真实 Android 真机、思源原生图入口、任务管理器互读、集市客户端可见性和 CardDAV 在线同步仍需单独验收；这些限制不会被本次隔离回归结果替代。
