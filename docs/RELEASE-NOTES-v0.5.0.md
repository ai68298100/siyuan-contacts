# 小驴人脉 v0.5.0

这是两台开发机合并后的统一功能版本，基于 v0.4.1。版本号从 0.4.1 升至 0.5.0，纳入两机合并后的组织、人物资料、移动端体验和数据安全改进。

## 新增

- **人物独立备注**：在人物详情中记录自由文本，保存到对应人物文档，可编辑或清空；不计入互动统计，也不作为当前迁移 JSON 的独立条目导出。
- **组织关系能力**：组织成员搜索与分页、人物和组织双向文档区块、共同背景、组织体检与逐项修复，并支持多段成员历史。
- **人物资料扩展**：人物别名、关系标签、资料档案及交换记录相关能力。

## 改进与修复

- 加强跟进、联系节奏、偏好和跨窗口刷新中的草稿保护、并发处理、失败状态与重试。
- 改进组织与联系人规模处理、图谱查询、移动端导航、窄屏布局、键盘焦点和无障碍提示。
- 加强组织投影、任务对账、设置恢复和人员服务桥在部分失败与迟到响应时的数据保护。

## 数据与迁移

- 插件自管 JSON 契约没有新增独立存储模块。
- 人物备注存入思源人物文档，以文档作为事实源；完整迁移 JSON 不单独导出备注。迁移到另一工作区时，人物文档本身仍需由思源的数据迁移流程带过去。
- 互动、跟进、节奏、提醒暂缓、收编索引与模板仍按现有完整迁移包规则处理。

- `pnpm check`：0 错误、0 警告；`pnpm test`：537/537。

## 未验证与已知限制

- 未在用户实际思源工作区完成端到端验收；隔离内核结果不等于真实工作区验收。
- Android 真机、系统返回、软键盘与安全区未验证；390px 回归只是隔离浏览器视口。
- 真实多窗口并发未验证。
- 思源原生图入口、任务管理器互读和集市可见性未验证。
- 完整英文界面仍未完成；插件不会在线同步 CardDAV/CalDAV。
