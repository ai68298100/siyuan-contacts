## P0 数据可信 第 50 轮：FUNC-01.13 存储锁接管审计（2026-09-30，续跑口令第 50 版驱动）

  持有方真挂死**并 steal——真挂死者不会再写入，接管不丢其数据；正常慢写在宽限内完成即被
  平台锁串行化，与接管者零重叠。非中止类锁错误照常抛出；无 Web Locks 降级队列语义不变。
