# v0.5.40 发布说明

发布日期：2026-10-23

## 核心亮点：五维全景档案正文同步引擎与全生命周期落盘闭环

针对用户提出的“每个人脉在插件中填写的所有的信息，都应该在文档中有体现，包括姓名、电话等基本信息，互动信息，各种其他信息，都应该在文档中有留存”的关键指示，本版本落地了全景正文沉淀体系：

### 1. 五维全景人脉档案正文同步引擎 (`doc-section.ts`)
- **全要素原子区块拆分**：
  - `## 人脉基本档案` (`custom-lvct-profile`)：电话、微信、邮箱、生日（含农历标识）、分组、标签、单位/学校/家庭、称谓；
  - `## 往来记录` (`custom-lvct-interactions`)：见面、电话、消息、聚餐、邮件等全部交往历史；
  - `## 待办跟进` (`custom-lvct-followups`)：Markdown 任务列表（`[ ]` 与 `[x]`）直观呈现到期日与跟进事项；
  - `## 人情往来` (`custom-lvct-exchanges`)：礼尚往来、收送礼、借还款等往来账目与状态；
  - `## 重要纪念日` (`custom-lvct-anniversaries`)：结婚纪念日、入职周年等特殊节点与农历标识；
  - `**相关人物**` (`custom-lvct-related`)：思源双链关系网。
- **纯函数分层与零外部依赖**：渲染逻辑收敛于 `src/domain/doc-section.ts`，确保纯函数架构守门 100% 遵从。

### 2. 详情页全生命周期增量联动
- 无论用户是在详情页中新建/完成跟进、添加纪念日、登记人情往来账目，还是修改基本档案，系统自动增量联动落盘；
- 各区块独立属性标记，内容未变绝不触发多余写操作，保证完全幂等与零性能损耗。
