# v0.5.38 发布说明

发布日期：2026-10-23

## 核心亮点：全方位 UI 广度与深度升级（胶囊体系化 / 现代微触觉反馈 / 交互类型规范化）

本版本继续深化用户体验打磨，重点聚焦信息视觉一致性、微交互触觉反馈与状态流转体验：

### 1. 互动分类胶囊体系化升级（消除生硬行内样式）
- 详情页互动分类标签全面重构为标准 `.b3-chip` 胶囊组件体系；
- 彻底移除硬编码内联样式，自动继承品牌主题主色微光环、暗色模式漫反射及键盘聚焦高亮轮廓；
- 悬浮反馈更自然，移动端触控目标与行高严格符合人体工程学规范。

### 2. 组织架构看板成员卡片现代微触觉反馈（Tactile Hover Lift）
- 组织工作台（Cockpit）中的各部门成员卡片新增平滑微浮动微动效（`transform: translateY(-1px); box-shadow: 0 2px 8px rgba(0, 0, 0, 0.05);`）；
- 增强视觉可点击感知，与名册舒适卡片、首页 Bento 瓷贴形成全插件一致的物理交互手感。
