# 小驴人脉 v0.5.14

本次补丁修复 vCard 导入遇到无名卡片时中止整份文件的问题。

## 修复

- `FN` 与 `N` 都为空的卡片按既有契约逐卡丢弃，不再阻断后续有效联系人。
- 文件中至少有一张有效姓名卡片时继续生成导入预览；所有卡片均无姓名时给出明确错误。
- 增加混合文件回归测试，覆盖首卡无名、后续有效卡的导入路径。
