# v0.5.26 发布说明

发布日期：2026-10-22

## 核心亮点：紧急修复联系人顶栏跑出屏幕与拉伸变形、修复组织成员筛选 0 人缺陷、重构分组与首字母胶囊

针对用户在实机使用中反馈的**“联系人顶栏直接跑出屏幕外、输入框被纵向拉伸成大白盒、分组按钮黑线毛糙与组织跳转筛选结果为 0 人”**等紧急问题，本版本进行了全方位的排查与紧急加固修复：

### 1. 紧急修复名册顶栏（Toolbar）排版跑出屏幕与纵向拉伸
- **消除冲突嵌套与水平越界**：彻底移除破坏 Flexbox 正常流的子容器与 100% 宽度锁死样式，恢复全端自适应流式排版，所有操作按钮无论屏幕多宽均自适应平滑折行，绝不越出屏幕右侧；
- **固定单行输入框高度（38px）**：彻底消除此前在垂直 Flex 容器中搜索输入框被纵向拉伸为 150px 巨型白块的异常表现；
- **自适应边距与容器防抖**：顶栏在各种宽度和移动端下均整齐有序。

### 2. 彻底修复组织卡片跳转名册筛选结果为 0 人的致命 Bug
- **根因彻底修复**：此前从组织卡片点击「成员」跳转名册时，因缺少 `itemIds` 且 `matchesProfileFilters` 仅检索 `work` 分类，导致归类为 `unspecified`（其他组织）的成员被漏判，最终名册被空 Set 过滤而显示 0 人；
- **全归属综合检索与成员映射**：
  - `matchesProfileFilters` 升级为全面覆盖 `work` 与 `unspecified` 全部分类；
  - 名册筛选逻辑针对组织跳转增加动态自愈容错，支持按 `memberDocIds` 与组织名称直接精准检索；
  - 修复后点击任一组织卡片上的「成员」，名册立刻精准展现全部在职与历史成员（如 19 人全量呈现）。

### 3. 重构常用分组胶囊（Group Tabs）与 A-Z 索引条
- **消除生硬黑线与样式割裂**：废除调用 SiYuan 原生 `.b3-chip` 带来的粗硬黑框与锐角违和感，重构为现代高质感轻圆角胶囊（`.lvct-people__group-tab`）；
- **优雅的状态色彩体系**：激活项采用柔和的主题淡色微背景与高亮边框，星标常用项专享暖金微光；
- **消除叠词重复**：A-Z 索引条首项优化为清晰的 `A-Z` 按钮，消除与上方「全部 (N)」重复的视觉认知负担。
