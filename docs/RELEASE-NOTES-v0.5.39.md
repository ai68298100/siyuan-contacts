# v0.5.39 发布说明

发布日期：2026-10-23

## 核心亮点：全生态中枢联邦对齐、暖干邑橙宝珠美学与集市自适应排雷

本版本严格遵循快门中枢下发的《小驴生态中枢统领指令》，全面落地 Epoch 6 跨插件联邦互通与集市检索标准：

### 1. 跨插件生态联邦协同（SDK 标准化）
- **纠偏事件监听**：规范采用 `subscribeEcosystemEvent` 与 `ECOSYSTEM_EVENTS` 标准总线，精确监听小驴打卡（`checkin:event-recorded`）、小驴拾遗、小驴闪卡、小驴考试等广播；
- **人脉互动联动打卡**：记录互动事实时安全探测并自动联动小驴打卡行为记录，未安装时安静降级；
- **雷切动态小组件接入**：向小驴雷切工作台注册 `contacts-upcoming` 小组件，实时呈现生日与待跟进人脉。

### 2. 视觉资产与美学体系对齐
- **顶栏单色图标升级**：`iconLvContacts` 全面升级为线条匀称、与新版橙底天青宝珠 Logo 1:1 呼应的 32×32 矢量线稿；
- **注入暖干邑橙（`#EA580C`）与天青宝珠（`#0284C7`）** 专属品牌变量与圆角阶梯；
- **弹窗标题徽章体系**：弹窗标题栏统一采用 `.lv-dialog-title-wrap`（左嵌暖干邑橙底白标徽章）。

### 3. 集市抓取与移动端深度排雷
- **补齐“小驴”品牌关键词**：在 `plugin.json` 中前置补齐 `["小驴", "小驴人脉", "xiaolv", "lv"]`，集市精准检索秒级直达；
- **独立设置窗口与兼容性**：新增 `"settingsWindow": true`，统一最低支持版本为 `"3.8.4"`；
- **移动端键盘动态避让**：接入 `window.visualViewport` 监听，输入法升起时自动提升弹窗底边距，防遮挡操作。
