## 复现步骤、预期与证据

每页按以下步骤复现适用状态。未覆盖格保持 `△/H`；新截图必须链接实际生成文件，不能沿用历史截图名宣称本轮验收。

| 状态 | 触发步骤 | 必须观察的结果 |
|---|---|---|
| 首次/加载 | 清缓存进入；挂起读取 Promise | 骨架/加载说明，不把未读完显示为 0 或正常空库 |
| 正常 | 合法人、组织、互动/计划夹具 | 事实来源/稳定目标正确；主操作到达页面成功出口 |
| 空 | 分别注入空库与无命中筛选 | 说明空的范围，有创建或清除筛选入口 |
| 部分/未知 | 第 2 项失败、响应丢失、写后回读失败 | 成功项和输入保留；未知与确定失败分开，不自动重建 |
| busy | 挂起保存/导出/扫描/AI/恢复 | 阻断重复提交及 X/Esc/遮罩/切页卸载 |
| 成功 | 返回可回读核实的事实 | 计数与事实一致，只回填存活实例/原目标 |
| 失败/重试 | 权限、坏结构、超时；恢复后显式重试 | 保留输入、只补可核实项，错误不变成空态 |
| 不可用 | 未初始化/AI 关闭/本人缺失/桥离线 | 解释缺失能力，核心手动路径可达 |

| 控件族 | 实际结果/名称来源 | 失败回执与边界 |
|---|---|---|
| 导航/返回/关闭 | 文字/aria-label；切页和关闭 scope | busy 阻断、草稿确认；来源恢复待 UX-002 |
| 首页统计/人物/更多处置/记录 | 人名与动作文字；下钻、互动、跟进、暂缓/撤销 | 行内错误和保留备注；批量统一结果待 UX-003 |
| 搜索/筛选/视图/列/卡片/表格 | label/aria-label/文字；仅改变列表与偏好 | 无匹配清除入口；隐藏选择/未知最近互动另验 |
| 新建/编辑/补录/批量/解绑 | 表单 label/动作；按稳定目标写字段/解绑行 | 逐字段失败/未知，原文档不删除 |
| 互动/任务/关系 | 人物/动作；事实与文档投影分别核实 | 未对账/投影失败分开，只补可核实步骤 |

| 图谱/查询/导出/画布工具 | aria-label/文字；范围/查询/文件 | 原生降级/范围说明；画布键盘替代未完成 |
