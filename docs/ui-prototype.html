📋 设计总览页（本页为设计说明，非实现画面）
产品定位（源自仓库分析）：在思源笔记内管理人脉——「一人一文档，数据库作主干」。联系人是普通思源文档（双链/搜索/同步照旧），结构化字段存思源原生数据库（AV），插件负责管理界面。人物文档与数据库保留；互动与偏好需另行备份。插件无遥测，AI 仅在主动操作时向用户配置端点发送内容，思源同步由用户控制。当前功能范围与后续批次见 产品总计划；本原型不代表全部能力已实现。

五条设计原则

① 思源原生感：色彩一律取 b3 CSS 变量、控件形态对齐思源设置页，插件像"长出来"而非"贴上去"。 ② 双向出入口：人脉活在文档里——文档可进（档案条/反链），插件可出（打开文档/写参与人员区块）。 ③ 渐进披露：列表 → 侧栏 Peek → 完整文档三级详情深度，默认不打断当前任务。 ④ 本地可信：AI 一律显式触发、可关；所有外发行为在界面上明示。 ⑤ 为演进留白：导航、筛选栏、设置分区按"组织/关系库/AI 建议"二期功能预留扩展位。
