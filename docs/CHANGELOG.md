## [0.4.1] — 2026-09-30（已发布：https://github.com/ai68298100/siyuan-contacts/releases/tag/v0.4.1）

v0.4.0 的紧急修复版：修复插件在真实宿主中无法加载（顶栏无入口按钮）的问题。

### 修复

- **插件加载失败**（v0.4.0 回归）：`data/interactions.ts` 与 `services/ai-extract.ts` 中的
  两处运行期动态 `import()` 在 CJS 产物中被 Rollup 拆成独立 chunk，`index.js` 顶层出现
  `require("./interactions-xxx.cjs")`——宿主插件 loader 的 require 只认 `siyuan`，
  加载即抛错（v0.3.0 发布产物中动态 import 均被内联，故未暴露）。两处已改为静态导入
  （均无循环依赖：其一与同文件既有静态导入同模块，其二目标模块不反向依赖本模块）。
- **防线**：`check:release` 新增产物形态门禁（dist 禁止独立 js chunk、index.js 的 require
  仅限 siyuan）；架构守门测试新增「全 src 禁运行期动态 import」。

## [0.4.0] — 2026-09-30（已发布：https://github.com/ai68298100/siyuan-contacts/releases/tag/v0.4.0）

v0.3.0 之后的第一个功能版本：P0 数据可信十四项收口 + 本人档案 / 组织模块 / 双图谱
三大能力（B11/B13/B14）与基础资料投影（B12）。实现与验收证据见 [PROGRESS](PROGRESS.md)
第 46~78 轮与 [PAGE-STATUS](PAGE-STATUS.md)；组织契约见 [DATA-CONTRACT](DATA-CONTRACT.md) §8。

### 新增

- **本人档案**（B11）：初始化后自动建档「我自己」并写身份标记（幂等续建）；名册与统计
  自动排除本人；联系人卡片「本人」徽标；设置页指定/改绑（显式操作，拒绝静默改绑）。
- **组织模块**（B13）：
  - 组织 = 文档 + `custom-lvct-org` 标记区块（不混入联系人数据库）；成员关系存
    `org-membership.json`（多组织/多段历史/在职离职，跨库 relation 经隔离内核实证否决）；
  - 工作台组织视图：组织卡片网格（活跃在前/归档垫底）、概要统计、侧栏正式导航、
    默认打开页可选组织；
  - 组织管理弹窗：新建、成员增删、成员字段行内编辑（部门/职位/加入/离开/状态，
    身份字段不可变、日期写前拒绝）、组织改名（renameDoc 实证接入）、归档/恢复
    （标记区块值 archived 语义，文档与成员记录保留）；

  - **共同背景**：同组织联系人投影（重叠期间、同期/同组织区分——加入时间未知不推断
    同期；排除本人；零写入、不产生称谓）；点击同伴原地切换详情。
- **双图谱**（B14）：
  - 图谱页「关系图 / 文档引用」双模式：文档引用图以内核原生图数据为源
    （`getLocalGraph` 双向一度 / `getGraph` 全图，参数与元素字段经隔离内核实证），

    组织节点点击跳组织视图 + hover 卡；

- **基础资料投影**（B12）：联系人卡片「单位行」（组织名 · 部门，活跃口径）、表格

## [0.2.1] — 2026-09-28

修复首次引导（初始化向导）在真实宿主上的两个阻塞缺陷；v0.2.0 首发用户可能停在

### 修复

- **首次初始化必失败**：写入端点 `insertBlock` 的返回体是事务结果数组
  （`[{doOperations:[…]}]`），api 层此前按对象读取，建库第一步抛「未返回新块 ID」。
  现按数组消费（两种形状都容忍），`insertBlock` 的 DOM 与 markdown 两种写入同时修复。
- **数据库物化参数错误**：`renderAttributeView` 的 `createIfNotExist` 传了 `false`，
  全新数据库块上内核返回 `attribute view not found`；改为 `true`（物化后调用幂等）。
- **重试永远撞名**：初始化链改为**幂等可续建**——按名复用已有笔记本、按标题找回
  「联系人总表」、按 `type='av'` 找回数据库块并从 `blocks.markdown` 还原 `avId`、
  按列名+类型对账只补缺失列、回链列已在则跳过双向配置；不重复建、不删除任何已有内容。

修复：首页“查看全部”深链
（生日、久未联系、待办跟进入口现在把完整人物集合带到联系人页，并加入桌面与 390px UI 回归断言。）

修复：农历生日排序按阳历发生日误算
（`isLunar=true` 时直接把存储值的月日解释为农历月日，再换算为当年的公历发生日；生日列表和提醒因此能正确混排。）

新增：生日历法标注
（联系人卡片、联系人表格、详情页、首页近期生日和编辑页均明确显示“公历/农历”，编辑农历生日时说明年份只作出生年份。）

新增：编辑页补充工作单位、学校与我的关系
（可直接填写关系称谓，并从活跃组织中选择工作单位或学校；保存后写入关系称谓记录和组织归属历史，编辑器关闭守卫也会提示未保存资料。）

- **新增 联系人显示偏好**：卡片/表格默认形态、表格列显隐与顺序持久化；「姓名」列固定显示。（F02）
- **新增 组合筛选**：标签全部/任一、最近互动日期范围、从未联系；生效条件可视、可逐项清除。（F03）
- **新增 保存常用视图**：命名保存筛选与排序，应用时按当次名册重新求值；支持改名/覆盖/删除。（F04）
- **新增 疑似重复人物检查**：按规范化电话/邮箱与同名给候选与理由，并排资料、只提示不合并。（F13）

### 主动联系闭环

- **新增 跟进事项**：日期型联系计划，支持语义化推迟（明天/三天后/下周一/一个月后/指定日期）、完成、取消与重开；完成不自动写互动。（F05）
- **新增 按人物联系节奏**：为个人覆盖久未联系阈值或暂停提醒，仅影响首页提醒、不写数据库字段。（F06）
- **新增 今日行动清单**：生日、联系节奏与跟进事项三源按人聚合，一人一卡多原因徽标，逾期可批量顺延到今天。（F07）
- **新增 打开工作台关注摘要**：当日摘要横幅（数量与行动清单同源），可当日不再展示；不发送宿主通知。（F08）

### 记录与回顾

- **新增 互动记录模板**：内置见面/电话/聚会模板，支持 `{{姓名}}` 等本地变量；应用不覆盖草稿、不自动提交。（F09）
- **新增 互动日期回顾**：日期范围、最近 30/90 天快捷项、按月分组与「历史上的今天」。（F10）
- **新增 会面简报 Markdown 导出**：资料、最近互动、未完成跟进、重要日期、相关人物与共同出席，预览与下载一致。（F11）
- **新增 交往回顾报表**：按月/自选区间的互动次数、同场活动数、联系人数、来源分布、Top 排行与上期对比，口径可解释。（F12）

### 导入与迁移

- **vCard 导入诊断**：逐项三段报告单（成功/跳过/失败/待核对），重试前先核对名册，不重复建人。（F14）
- **互动备份差异明细**：合并前按事件预览将新增/将跳过与删除标记影响，人物不可达显式标注。（F15）
- **关系查询结果导出**：路径链式呈现并可导出 Markdown 说明，含图规模、筛选条件与范围免责。（F16）
- **重复检查**（见 F13）与**图谱结果导出**（见 F16）同属 D 批整理与迁移主题。
