## [0.3.0] — 2026-09-29（候选，待作者推送/发布）

真实使用反馈批次 2–5 全部落地的版本：移动端、首页行动区、快速录入、数据安全与
跟进原生待办同步。详细实现与验收证据见 [PROGRESS](PROGRESS.md) 与
[PAGE-STATUS](PAGE-STATUS.md)（十页状态矩阵）。

### 新增

- **可搜索选人器**（B03）：详情相关人、图谱关系中心/对比人物统一替换全量下拉；
  输入即筛、键盘上下+回车、分组标签提示、排除本人与已选。
- **资料完整度筛选与串行补录**（C03）：「更多筛选 → 资料完整度」四类缺口；
  「逐个补录」一人一屏只列缺失字段，保存进下一位，不清空已有资料。
- **粘贴并识别**（FAST-01.1/01.2）：新建/编辑联系人「📋 粘贴并识别」——本地解析名片文字、
  聊天记录、键值清单、frontmatter、表格行；电话/生日规范化并保留原文；冲突默认不覆盖；
  可复制空白模板。
- **识别资料**（FAST-01.3）：编辑器右键「人脉：识别资料」——选中文本（带字数）或整篇文档
  本地识别；人物文档→补充此联系人、普通笔记→新建预填；不误读其他窗口。
- **AI 结构化抽取**（FAST-01.4）：捕获 AI 分析升级为版本化 JSON 四类候选（资料补充/互动事实/
  跟进候选/关系候选），分组勾选确认后写入；非法日期/超限丢弃并计数；关系候选仅展示不写库；
  无契约字段不静默入库。
- **今日行动分组折叠**（B01）：逾期/今天/本周/久未联系/从未互动五组，组头计数可折叠；
  「从未互动」单独归组默认折叠，按最近收编倒序（C02）。
- **行内快捷处置与提醒暂缓**（B08）：生日「跳过本年」、久未联系「顺延 3 天/1 周/1 月/不再提醒」、
  从未互动「今天先跳过」；新存储 `reminder-dismissals.json` 只屏蔽提醒呈现、不改统计口径；
  设置页「已暂缓的提醒」一键恢复；操作后通知带「撤销」（C06 会话内撤销，六类处置覆盖）。
- **收编宽限期**（C02）：新收编联系人默认 14 天（可调，0=关闭）不计入「从未互动」提醒；
  「从未互动」组「全部顺延 30 天」批量安顿，可一次性撤销；新存储 `person-registry.json`
  收编时间索引。
- **资料体检**（C04/FUNC-01.4）：设置页十类只读巡检（缺电话/缺生日/缺联系方式/无分组无标签/
  可疑生日/悬空关系/跟进不可达/孤儿互动/疑似重复/长期无互动），「查看这 N 人」跳转联系人页聚焦。
- **完整迁移包**（C08/FUNC-01.6）：互动+跟进+节奏+提醒暂缓+收编索引+模板六模块合并导出与恢复
  （模块预览→确认合并，现状优先不重复）；明示非思源原生数据字节级备份、不含锚点。
- **跟进 → 原生待办双向同步**（B07）：跟进以原生任务块写入人物文档（`custom-lvct-followup`
  关联键可反查），文档勾选/取消/改期/删除与插件库双向收敛；文档为准、不产生重复任务
  （契约 §3.1，隔离内核实证 12/12；真机核对待作者）。
- **锚点找回**（B09-8/FUNC-01.8）：设置页重绑弹窗「扫描全库候选（只读）」——遍历笔记本找
  「联系人总表」与数据库块，按字段对回数排序候选；零写入、不自动建第二套数据。
- **一键建跟进**（C07）：行动区「⋯ → 建跟进（联系一下）」默认今天+7 天。
- **首页各列表「查看全部」**（FUNC-01.1）：生日/久未联系/待办跟进服务层不再静默截断，
  超出首屏给「查看全部（共 N 条）」。
- **跨窗口刷新**（FUNC-01.7）：其他窗口的数据变更防抖通知本窗口原地刷新（筛选/Peek 上下文
  保留）；草稿编辑中给可见提示不静默覆盖。

## [0.2.1] — 2026-09-28

修复首次引导（初始化向导）在真实宿主上的两个阻塞缺陷；v0.2.0 首发用户可能停在
「已存在同名笔记本「人脉」」而无法继续（首次启动实故报告）。证据与复现见
[PROGRESS](PROGRESS.md) 与 `scripts/spike/init-resume-spike.mjs`（隔离内核 21/21）。

### 修复

- **首次初始化必失败**：写入端点 `insertBlock` 的返回体是事务结果数组
  （`[{doOperations:[…]}]`），api 层此前按对象读取，建库第一步抛「未返回新块 ID」。
  现按数组消费（两种形状都容忍），`insertBlock` 的 DOM 与 markdown 两种写入同时修复。
- **数据库物化参数错误**：`renderAttributeView` 的 `createIfNotExist` 传了 `false`，
  全新数据库块上内核返回 `attribute view not found`；改为 `true`（物化后调用幂等）。
- **重试永远撞名**：初始化链改为**幂等可续建**——按名复用已有笔记本、按标题找回
  「联系人总表」、按 `type='av'` 找回数据库块并从 `blocks.markdown` 还原 `avId`、
  按列名+类型对账只补缺失列、回链列已在则跳过双向配置；不重复建、不删除任何已有内容。

### 新增

- **向导预检与续建入口**：运行前显示「将新建 / 将复用哪些内容」并支持「重新检测」；
  失败后按钮变为「继续初始化」，提示已建成的部分会被保留、可从断点续建。
- 双语键表扩至 452 对（新增初始化预检与进度步骤 30 个键，zh-CN 与 English parity 守门）。

### 验证

- 单测 140/140（新增 `tests/init-plan.test.ts`：列对账与 avID 还原 9 项）；桌面隔离
  回归 60/60、移动视口回归 61/61（各新增全新初始化、续建、向导失败可继续 3 项）；
  真内核联系人流程 E2E 10/10；生产构建与发布门禁通过。
- 实际宿主、真机与实际多窗口验收未执行（按作者要求跳过），本补丁验收证据来自隔离内核
  （v3.8.5）与隔离浏览器。

## [0.2.0] 候选（candidate）— 2026-09-28

自 v0.1.0 以来的 16 项增量功能，按主题分组。详细实现与验收证据见 [PROGRESS](PROGRESS.md)。

### 查人与整理

- **新增 统一导出中心**：设置「数据」集中导出全量名册 vCard 与互动事件 JSON，显示数量并明示备份边界。（F01）
- **新增 联系人显示偏好**：卡片/表格默认形态、表格列显隐与顺序持久化；「姓名」列固定显示。（F02）
- **新增 组合筛选**：标签全部/任一、最近互动日期范围、从未联系；生效条件可视、可逐项清除。（F03）
- **新增 保存常用视图**：命名保存筛选与排序，应用时按当次名册重新求值；支持改名/覆盖/删除。（F04）
- **新增 疑似重复人物检查**：按规范化电话/邮箱与同名给候选与理由，并排资料、只提示不合并。（F13）

### 主动联系闭环

- **新增 跟进事项**：日期型联系计划，支持语义化推迟（明天/三天后/下周一/一个月后/指定日期）、完成、取消与重开；完成不自动写互动。（F05）
- **新增 按人物联系节奏**：为个人覆盖久未联系阈值或暂停提醒，仅影响首页提醒、不写数据库字段。（F06）
- **新增 今日行动清单**：生日、联系节奏与跟进事项三源按人聚合，一人一卡多原因徽标，逾期可批量顺延到今天。（F07）
- **新增 打开工作台关注摘要**：当日摘要横幅（数量与行动清单同源），可当日不再展示；不发送宿主通知。（F08）

### 记录与回顾

- **新增 互动记录模板**：内置见面/电话/聚会模板，支持 `{{姓名}}` 等本地变量；应用不覆盖草稿、不自动提交。（F09）
- **新增 互动日期回顾**：日期范围、最近 30/90 天快捷项、按月分组与「历史上的今天」。（F10）
- **新增 会面简报 Markdown 导出**：资料、最近互动、未完成跟进、重要日期、相关人物与共同出席，预览与下载一致。（F11）
- **新增 交往回顾报表**：按月/自选区间的互动次数、同场活动数、联系人数、来源分布、Top 排行与上期对比，口径可解释。（F12）

### 导入与迁移

- **vCard 导入诊断**：逐项三段报告单（成功/跳过/失败/待核对），重试前先核对名册，不重复建人。（F14）
- **互动备份差异明细**：合并前按事件预览将新增/将跳过与删除标记影响，人物不可达显式标注。（F15）
- **关系查询结果导出**：路径链式呈现并可导出 Markdown 说明，含图规模、筛选条件与范围免责。（F16）
- **重复检查**（见 F13）与**图谱结果导出**（见 F16）同属 D 批整理与迁移主题。

### 其他

- 首页/图谱/报表/详情/档案条/捕获向导/初始化向导等接入双语键表（zh-CN 与 English，423 对，parity 守门）。
- 设置页「关于」版本号动态化；移动端与桌面隔离回归持续扩展。

### 范围与边界

- 实际宿主、真机与实际多窗口验证按作者要求跳过，未计为通过；详见 [RELEASE](RELEASE.md) 手工验收表。
- 服务层失败原因与原生确认弹窗文案以中文为主（已知限制）。
