# 写型思源冒烟运行约定

本仓库的内核脚本分成两类：

- 只读走查：只调用查询/读取接口，不写块、不建删笔记本、不改 petal 存储，可以在日常工作区并发执行。
- 写型冒烟/基准：会建删笔记本、写块或触发插件写入，只能打独立靶场，禁止直连正在使用的工作区。

写型脚本必须使用 `scripts/lib/smoke-kernel.mjs` 的共享防线。目标地址和 token 从
`SIYUAN_BASE_URL`、`SIYUAN_TOKEN` 读取；命令行参数优先时由具体脚本自行解析。缺 token
必须明确失败或按该脚本既有语义 SKIP，不能内置默认 token、默认工作区路径或偷偷切到 6806。

启动时先列出笔记本并清扫本项目注册前缀下的崩溃残留，再检查目标是否只含本项目临时库。
发现任何非本项目前缀的笔记本即拒绝写型测试；只有明确设置 `SIYUAN_E2E_ALLOW_SHARED=1`
才能豁免。清扫只允许删除本项目前缀，不能按“测试库”模糊匹配。

同一脚本内为了重启回读而再次启动内核时，不重复执行残留清扫；本轮已创建的临时库要保留到
回读完成，最后由脚本按自身 ID 显式删除。这样不会把当前测试对象误删成“上次崩溃残留”。

推荐靶场：用独立 workspace 启动第二个思源实例，端口从 6807 起自动顺延，只安装被测插件；
每个插件项目拥有自己的 workspace，不跨项目共用。同一内核实例上的写型冒烟串行执行，
只读走查才允许并发。靶场 token 与主工作区不同，运行前从该实例设置→关于获取。

涉及真实 AI 模型的检查步默认跳过，只有 `SIYUAN_E2E_AI=1` 才能启用；测试输入必须是
虚构文本，报告不记录 token、密码、正文或模型回复。

推荐命令：

```powershell
$env:SIYUAN_BASE_URL = "http://127.0.0.1:6807"
$env:SIYUAN_TOKEN = "<靶场 token>"
node scripts/e2e/contacts-flow.mjs
```

`contacts-flow.mjs` 支持 `--base-url`、`--token`、`--workspace`，命令行参数优先于环境变量；
`services-flow.mjs` 和 `load-check.mjs` 会启动自己管理的本地隔离内核，支持 `--workspace`，不接受
外部目标参数。后两者会修改插件存储或 petal 状态，连接日常内核会被直接拒绝；需要验证已有内核时，
另写只读走查，不把“能连上”当成写入授权。

在用工作区运行写型脚本应看到“目标不是隔离靶场”的拒绝提示。空靶场全套通过后不应留下
`lvct-contacts-*` 临时库；人为留下同名前缀残留时，下一次启动会先清扫。可选脚本继续以
SKIP=0 结束，必过脚本失败仍返回 1，防呆逻辑不得改变原有退出码语义。
