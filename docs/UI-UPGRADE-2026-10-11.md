# UI 现代化升级记录（2026-10-11）

本轮以用户提供的设置页截图为视觉参考，结合 Notion、Linear、Google Contacts、Apple Contacts、Monica 和 Airtable 等产品中已经验证的界面模式，对小驴人脉的工作台进行了整体升级。借鉴的是信息层级、留白、状态反馈和控件节奏，不复制这些产品的业务内容。

## 联系人、组织与正常详情窗口

整体：继续使用冷蓝灰画布与白色卡片，把人物详情从侧边抽屉改为正常窗口，优先改善阅读空间和长资料表现。

优化：窗口与卡片层级

- 所有人物详情入口统一为桌面居中 720px 宽窗口，手机端使用完整屏幕；白色标题区与内容连续，细分隔线建立层级。
- 详情头部按可用宽度排列动作，关系摘要按可用空间自动排列；长姓名、分组和资料允许完整换行。
- 联系人资料不再挤在头像右侧，改用全宽摘要；已核实空字段省略，其他组织、历史经历、待核对和未知状态保留。
- 组织 Logo 统一 40px，名称、简称、归档标识分层排列；归档文字保持对比度。

修复：实际截图和交互检查发现的问题

- 联系人桌面网格按内容撑开行高，修复长卡片内容越界并与下一行重叠。
- 描边图标显式取消填充，防止思源通用 SVG 规则把时钟、邮箱等图标填实。
- 详情中打开新建组织使用正确窗口层级；子浮层已处理的 Esc 不再向外关闭人物详情。
- 组织窗口关闭只核对自身草稿与保存状态，修复父编辑器等待组织创建导致 X/Esc 无法关闭；候选刷新后恢复到当前可用入口。
- 选人器搜索框聚焦时保留滚动位置，避免桌面窗口自动滚动使刚打开的浮层立即关闭。
- 详情返回按稳定联系人 ID 恢复名册入口，避免保存后的卡片重建使焦点落空；慢刷新期间用户转向其他控件时，保留新的焦点与滚动位置。
- 空资料判断包含其他组织、历史和不可达记录，避免只保留毕业/离职经历时显示“资料待补充”。

新增：专项验收

- 长联系人、大尺寸 Logo 与长简称、人物窗口覆盖 320/390/768/1280px 明暗主题，使用真实思源样式。
- 联系人截图通过实际名册、存储与组织投影链路生成；截图等待有限进入动画结束，避免捕获半透明过程帧。
- 卡片回归覆盖空资料、其他组织、毕业历史、待核对、组织未知、称谓未知、未设置本人、长联系方式和宿主图标规则。
- 返回焦点回归覆盖慢刷新后用户转向搜索、改名后排到第 201 位，以及旧返回等待期间打开另一人物。

验证：类型与 Svelte 检查 0 错误 / 0 警告，域层 558/558，桌面 UI 342/342，移动模拟 UI 343/343，宿主样式 UI 342/342；28 张最终截图、原型脚本语法与静态 ID 检查通过。构建、产物完整性与 SHA-256 校验及差异检查通过。手机端使用隔离浏览器视口模拟。

## 本次更新（2026-10-11）

整体：参考小驴打卡的视觉令牌和页面材质，统一小驴人脉的桌面、移动端及明暗主题表现。

新增：青色系品牌视觉令牌

- 新增稳定的浅色/深色底板、青色主操作、珊瑚色提醒、控件圆角、阴影、字体和状态色配方。
- 将品牌渐变限制在品牌标识和特殊引导场景，普通操作使用清晰的主题实色。

优化：整体材质与页面层级

- 工作台、联系人、组织、设置、图谱和弹窗统一使用同源表面、边界和悬停语言。
- 通过明确的 app、base、surface、elevated 四级层次提升页面质感，减少装饰性背景对内容的干扰。
- 移动端沿用同一套层级和触控尺寸，底部导航、横向分区和卡片在窄屏下保持稳定。
- 浅色模式的主要卡片、面板、弹窗和工具区统一使用纯白表面，取消卡片渐变，靠发丝边界和柔和阴影建立层次。
- 浅色画布改用独立的冷蓝灰背景，卡片和面板保持白色；青色承担品牌、选中态和主要操作，与小驴打卡的紫色体系区分。

修复：主题下视觉不一致

- 修复浅色和深色主题中背景、按钮、卡片、选中态和状态色层级不统一的问题。
- 修正设计令牌注释与实现不一致的说明，明确明暗模式由宿主主题上下文触发，插件内部保持稳定配方。
- 修复 Cytoscape 图谱在宿主主题切换后文字和边界颜色不刷新的问题，图谱现在会保留稳定默认色并实时读取主题颜色。
- 提高浅色主按钮的对比度，区分装饰色、填充色和正文色，避免主操作在浅色背景上发灰。

## 最终整理

## 色彩体系更新（2026-10-11）

整体：将运行时与原型的品牌强调从紫色统一调整为青色系，形成小驴人脉独立的视觉识别。

新增：青色主色与珊瑚提醒色

- 品牌渐变、主按钮、焦点环、导航选中态和组织节点统一使用青色语义令牌。
- 生日、提醒等需要引起注意的内容使用珊瑚色，与青色主操作保持清晰区分。

优化：浅色与深色表面配方

- 浅色背景改为冷蓝灰，卡片、面板、弹窗和输入区保持白色，减少大面积着色。
- 深色表面、选中底和图谱边界改为青灰配方；阴影去除紫色偏色，保留层次和对比度。

修复：残留紫色视觉引用

- 组织节点固定色、主色浅底、主按钮填充和主色文字均改用青色对比度配方。
- 文档、原型和隔离测试夹具中的当前视觉说明与实际青色实现保持一致。

新增：移动端滚动与长名称的视觉边界

- 联系人标签较多时增加右侧渐隐和滚动留白，让用户能识别还有内容可以横向浏览。
- 组织卡片标题允许安全换行，简称和归档状态保持独立，不再因长名称挤压或溢出。

优化：按钮和导航的状态表达

- 移动底部导航隐藏桌面侧栏遗留的活动竖线，当前项只保留图标、文字和背景强调。
- 首页统计、摘要、组织读取、设置预览等按钮在忙碌或前置条件不足时统一显示原因提示。

修复：禁用控件的交互反馈

- 禁用的首页快捷操作、图谱工具和组织操作不再显示悬停、按下或可点击反馈。
- 组织列表卸载或刷新切换时丢弃迟到结果，避免旧数据回填当前页面。

新增：关键操作的可用状态反馈

- 关系图导出、适应、缩放和重新布局在数据或画布未准备好时明确禁用，并通过悬停提示说明原因。
- 组织管理中的新建、添加、接替、移动和加载更多在禁用时提供对应原因提示。

优化：整体页面质感与响应式布局

- 工作台画布去除装饰性径向光晕，保留中性背景、表面层级和轻量边界，内容获得更稳定的视觉焦点。
- 组织卡片最小高度收紧，减少少内容卡片的空白；设置页移动端分区导航改为单行横向滚动，不再被网格规则挤成多行。

修复：图谱和设置页的交互细节

- 图谱工具按钮的悬停、按下和禁用态分离，禁用时不再显示可点击光标或按下反馈。
- 移动端设置导航新增分区时仍保持触控尺寸和表单首屏空间。

## 今日行动专项整理

优化：分组、对齐与长内容阅读

- 行动卡使用白色表面、统一内边距与单列分组；姓名/资料、原因和操作采用稳定的布局，处理与更多按钮固定宽度。
- 卡片宽度不超过 660px 时信息与原因堆叠，不超过 440px 时正文占满整行、操作位于下一行；姓名、资料与提醒不使用省略截断。
- 行动相关样式只作用于行动卡，近期生日、久未联系和待办列表保留各自的信息布局。
- 首页次级卡片按实际空间自动排列，避免平板侧栏挤压双列内容；标题栏采用简短动作文字和完整无障碍说明，次按钮清除宿主默认主色内阴影。
- 原型同步分组折叠、长姓名、多原因及顺延确认演示；实现保持已有提醒、撤销和重试流程。

新增：可见行动区视觉验收

- 专用 `LVCT_SHOT_VIEW=actions` 夹具包含长姓名、多原因和组织概览，覆盖 320/390/768/1280px 明暗主题及真实思源样式。

- 测试承载框高度独立于近似宿主样式，避免替换真实宿主 CSS 时失去工作台滚动范围。

## 研究结论

- **中性画布 + 局部强调**：大面积使用主题中性色，青色品牌色只承担当前导航、主按钮、状态和头像识别，避免全屏高饱和渐变。
- **侧栏是稳定锚点**：品牌、主导航、低频入口和设置分组固定在同一层级；选中项使用浅色底和细内描边，不依赖粗重边框。
- **卡片需要呼吸而不是堆边框**：卡片统一 16px 圆角、轻描边和低强度阴影，悬停时通过边框和轻微位移反馈，不用明显黑影。
- **页面先显示任务再显示诊断**：首页行动、联系人搜索、组织筛选和设置保存状态保持清晰主次；低频工具收进次级行或菜单。
- **表单分段而非平铺**：输入框高度、标签字号、区块间距和标题层级统一；必填、可选、处理中、失败和可重试状态保持可见。
- **移动端保留同一套语义**：底部导航仍是工作台锚点，内容卡片改为单列，工具栏允许换行或横向滚动，触控目标不低于 40px。

## 参考图二次提炼（2026-10-11）

本次补充吸收用户提供的仪表盘、客服工作台和项目管理界面的通用优点，重点落在信息组织和反馈节奏，不复制业务内容或营销素材：

- **聚焦页头**：标题、范围、主操作保持同一条对齐线，每页最多一个主要提交动作。
- **指标带可下钻**：指标必须说明口径和范围，并能进入联系人、提醒或报表，不展示无法采取行动的装饰数字。
- **主内容 + 上下文侧栏**：来源、下一步和低频状态放在辅助区，移动端按内容顺序折叠，避免侧栏成为唯一入口。
- **事实型进度**：用覆盖比例、逐项结果和待处理数量表达资料状态，不把完整度包装成关系评分。
- **层次预算**：普通面板以背景和细描边分层，阴影只保留内容面与浮层两级；丰富度来自选中、加载、保存和失败反馈。

这些模式已加入 `docs/ui-prototype.html` 的 UI 规范页“视觉配方”预览，并在 `docs/UI-SYSTEM-SPEC.md` 6.5 登记为实现与验收基线。原型新增区域仍为演示数据，不改变运行时数据契约。
