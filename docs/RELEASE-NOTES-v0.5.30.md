# v0.5.30 发布说明

发布日期：2026-10-22

## 核心亮点：对照思源官方最新源码（v3.8.8）对齐 Petal 生命周期契约、加固存储读写真实性与生态深度结合

针对用户关于“深度审查思源官方最新源码、核对 Petal 生命周期契约、防范潜在冲突与推进功能结合”的指示，本版本对照思源官方最新源码（v3.8.8）展开了系统级源码核对与工程加固：

### 1. 对齐思源 Petal Lifecycle 核心契约与存储缓存黑洞消除
- **规避 loadData 内存缓存黑洞**：根据思源源码 `app/src/plugin/index.ts:456` 的底层机制，`loadData` 在请求异常时会回退兑现内存缓存 `data[storageName]`，导致回读验证发生“假收敛”；本版本在严格读取前显式清除该键内存缓存，强制穿透真实磁盘，保证写入回读验证 100% 真实有效；
- **对齐 `onDataChanged` 异步协调契约**：明确接收官方生命周期协调器传入的 `reason`（`sync` 跨设备同步 / `overwrite` 多窗口覆盖），协同思源官方的生命周期串行与等待队列。

### 2. 思源原生功能深度结合与规范化
- **规范标准双链格式**：一键复制双链引用严格规范为官方标准的 `((docId "姓名"))` 紧凑语法，消除多余内空格，确保在任何思源正文编辑器中粘贴即刻精准解析为人物块引用；
- **日程视窗极速直达**：首页 7 天时序滑轨直通人物详情面板，实现日程到人脉档案的秒级闭环。
