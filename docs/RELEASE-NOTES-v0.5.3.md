# 小驴人脉 v0.5.3

## 新增

- **组织资料与新建组织**：组织页、组织管理页和联系人入口支持新建组织；组织资料支持名称（必填）、简称、企查查链接、Logo、介绍、部门层级和自定义内容。
- **联系人扩展资料**：新建和编辑联系人可填写工作单位、学校、部门、与我的关系和组织任职日期，扩展内容可折叠填写。
- **生日历法选择**：生日字段可直接选择公历或农历模式，列表、卡片、详情和首页均明确标注历法。
- **提醒处置与恢复**：生日提醒提供“今天不再提醒”“未来 7 天不再提醒”“跳过本年”“不再提醒”，设置页提供恢复入口和撤销操作。
- **资料与交互审计**：补充组织资料迁移、联系人入口联动、失败重试、关闭守卫、移动布局和异步请求保护。

## 优化

- 统一联系人、组织、首页和设置页的搜索、筛选、空态、失败态、忙态和重试反馈。
- 统计卡深链、首页搜索清除、组织候选刷新和关系图设置联动保持状态一致。
- vCard 导入导出补充字段边界、映射统计、同名候选和农历标记说明。
- 设置页明确说明当前仍通过 vCard 文件交换，CardDAV 在线通讯录同步尚未接入。

## 修复

- 修复农历生日按阳历输入值排序的问题，按下一次实际发生日排序。
- 修复日期键、联系人资料、组织候选和组织 Logo 的非法值、读取失败及迟到回写问题。
- 修复弹窗关闭、批量操作、组织创建、导入导出和提醒恢复中的重复完成及过期状态更新。
- 扩展迁移包对组织资料和提醒暂缓数据的严格校验、锁内写入和写后回读。
