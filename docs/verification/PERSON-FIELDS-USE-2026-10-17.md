# 补充资料查找、复制与隔离 E2E（2026-10-17）

本轮继续开发 #51/#54，在已有重复条目、两层分组和个人备注保存修复上补齐详情使用流程。所有写入验收均使用脚本新建的 UUID 隔离思源工作区、回环端口和独立 Chrome profile；资料为虚构内容。没有连接日常用户库。本轮未提交、推送或发布。

## 已实现

- 阅读态按分组、条目名称和完整内容筛选；组名命中展示整组，条目命中保留组头。命中数不计组头，提供无结果和清空入口；不增加内核读取或持久索引。
- 筛选只改变展示。进入编辑始终取得完整快照，保存包含未命中条目；切人清空查询。
- 非空条目可显式复制完整原值，保留首尾空白、空行和特殊字符；成功、失败和等待有就近反馈。标准 Clipboard API 不可用时在原点击内同步使用 DOM copy，并恢复焦点与选区；异步拒绝不迟到启动第二次复制。
- 复制反馈按人物、条目和快照隔离。组件保留在途锁，公共 helper 另设页面内共享排他锁；关闭详情再打开另一人物仍不能发起第二个在途复制请求。请求不排队，结束后须显式重试，避免旧内容最后覆盖新内容。

存储仍沿用 D-0039 / DATA-CONTRACT §6A 的独立原生段落完整快照，没有新增 schema、AV 字段或插件 JSON。详情筛选不等于联系人全局检索。
