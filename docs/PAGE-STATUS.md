# 页面状态矩阵（PAGE-01.0）

> 责任文档：本文件是 `FEEDBACK-BACKLOG.md` `PAGE-01.0` 的交付物——逐页面登记「入口 → 主任务 →
> 数据范围 → 主操作 → 成功出口」与状态矩阵。每个状态格标注现状并关联截图、夹具与任务编号；
> 不以「页面能打开」作为通过条件。
> **状态标记口径**：✅ 已有且经夹具复现 ｜ ⚠️ 已有但待优化 ｜ ❌ 缺失 ｜ ➖ 该页无需此状态（须写理由）｜ ☐ 待核。
> 视觉验收统一用 `LVCT_HOST_BASELINE=1 node scripts/e2e/screenshot-settings.mjs`（宿主基线截图）与
> `pnpm test:ui[:mobile][:host]`（隔离回归）。2026-09-28 初稿：主路径四页（外壳/首页/联系人/详情）
> 完整矩阵；其余页面骨架，随对应批次补齐。

## 状态口径（每页必查，页面没有该状态时必须写「➖ 无需」的理由）

| # | 状态 | 说明 |
|---|---|---|
| S1 | 首次加载 | 首次进入无缓存时的呈现 |
| S2 | 骨架加载 | 异步数据期间的稳定占位（不跳动） |
| S3 | 正常有数据 | 主任务可完成的 happy path |
| S4 | 空 | 空名册 / 空结果 / 空配置，给出下一步 |
| S5 | 部分数据/部分失败 | 一部分加载或写入失败时的呈现 |
| S6 | 提交中（busy） | 异步动作防重复点击 |
| S7 | 成功反馈 | 写入后的可见确认（含可撤销入口） |
| S8 | 失败可重试 | 失败保留输入、给重试/查看详情 |
| S9 | 能力不可用 | 未初始化 / 桥未装 / AI 关闭时的降级 |
| S10 | 草稿未保存 | 离开前的守卫（B06 三选一） |
| S11 | 跨窗口数据变更 | 另一窗口改动后的刷新提示（FUNC-01.7） |
| S12 | 移动端 390px | 布局、触控 ≥40px、安全区 |
| S13 | 暗色主题 | 令牌化颜色、对比度 |
