# 小驴人脉 v0.5.1

v0.5.1 是 v0.5.0 之后的补丁版本，重点补齐联系人分组的实际使用范围，并收拢已验证的开发依赖更新。

## 新增

- **自定义联系人分组**：分组下拉框提供「自定义…」，支持输入具体名称，不再要求把特殊情况归入“其他”。
- 新建、编辑、资料补录、已有文档收编和批量编辑入口统一支持自定义分组。
- 已有自定义分组可以回显，并会进入联系人列表和关系图谱的动态分组筛选。

自定义名称会去除首尾空格；空值和界面内部占位值会被拒绝，不会写入思源数据库。`group` 仍使用原有 AV select 字段，思源会按写入值建立选项，不需要迁移数据。

## 文档与依赖

- README 中英文恢复小驴插件系列介绍，保留交流群 QQ 群 `871707735`。
- README 安装入口、版本说明和发布说明统一指向 v0.5.1。
- 合入已通过 CI 的常规依赖更新：`@lucide/svelte`、`@types/node`、`livereload`、`sass`、`vite`。
- SiYuan 类型包维持在 1.2.7；尝试升级到 1.2.9 的 Dependabot PR 因类型不兼容和 CI 失败而关闭。

## 数据与迁移

自定义分组复用现有联系人数据库字段，不增加新的插件存储键或迁移模块。既有联系人文档、数据库和插件自管数据无需迁移；跨工作区仍按 [数据契约](DATA-CONTRACT.md) 先迁移原生文档与数据库，再恢复插件迁移包。

## 验证与边界

发布前执行并记录 `pnpm check`、`pnpm test`、`pnpm test:ui`、`pnpm test:ui:mobile`、`pnpm build` 和 `pnpm check:release`。隔离回归不替代真实思源宿主、Android 真机、真实多窗口、原生图入口、任务管理器互读和集市可见性验收。
