# UI 隔离回归

运行 `pnpm test:ui`。脚本通过 Vite 加载真实 Svelte 组件与 Cytoscape，将 `siyuan` 模块替换为内存适配器；不会连接真实思源内核或写用户笔记本。运行 `pnpm test:ui:mobile` 可用 390px Chromium 视口补测移动布局。

## 环境

- 使用项目已有依赖，无需另装浏览器自动化框架。
- 默认查找 Windows 安装的 Chrome 或 Edge；其他位置可通过 `LVCT_TEST_BROWSER` 指定 Chromium 可执行文件。
- 使用 loopback 临时端口及独立临时浏览器目录；目录路径会输出到控制台，保留供排查。
- 测试容器宽度随视口收缩（上限 1000px），移动回归不再在固定桌面宽容器内运行。
- 最长等待 45 秒，失败或超时返回非零退出码。脚本结束关闭本次浏览器进程和开发服务。

## 持续检查

GitHub CI 安装 Chrome，通过 `LVCT_TEST_BROWSER` 指定可执行文件，依次执行桌面与移动视口回归。任一失败均阻止后续构建及产物上传。Linux/macOS 本地也可通过该变量指定 Chromium。CI 使用同一套内存替身，不代替真实思源宿主验收；工作流实际运行结果以推送后的 GitHub Actions 为准。

## 覆盖范围

1. 首页零人统计筛选不显示全部联系人，清除筛选后恢复列表。
2. 图谱正常挂载、悬停详情、空筛选销毁和重建画布。
3. 详情加载失败重试、空时间线跳转记录、提交后刷新时间线。
4. 首页打开详情并记录互动后，统计和久未联系提醒同步刷新。
5. vCard 新文件解析失败时清空旧计划并禁止提交。
6. 文档收编快速搜索时，旧请求不能覆盖新结果，关键词改变即清空勾选。
7. 快捷互动失败保留备注，重试成功后更新提醒。
8. 捕获宿主弹窗完成后可关闭，内容继承插件令牌。
9. 切换文档后不插入旧档案条，独立档案条具有明暗主题令牌。
10. 页面无未处理异常或响应式循环。
11. 外部设置入口可让已挂载工作台切换到设置页，新挂载工作台可直接以设置页作为初始视图。
12. 人物文档档案条的会前简报展示真实互动事实，不再保留占位文案。
13. 多人同场互动通过真实存储服务写入并回读，保留全部参与者，重复录入同一人保持幂等；持久化使用内存替身。
14. 外部人员桥重复人员、重复调用、并发调用仅计实际新增；写后回读失败拒绝返回成功。
15. 笔记捕获对参与者与双链去重，再次捕获返回零新增；内核与持久化使用替身。
16. 外部联动与笔记捕获拒绝空串、格式错误和不存在的日期，且不产生存储/内核调用；合法闰日按当地零点保存。
17. 按名捕获已有联系人时复用人物文档、记录互动与参与人员双链，不误报新建；重复姓名及文档选择重叠保持幂等。
18. 名册同配置并发请求合并，失效前的旧请求不能回填共享缓存；字段映射变化重查，失败后可直接重试。
19. 互动存储读取抛错时新增与删除均停止且不保存；展示仍容错，恢复后追加保留旧记录并可正常墓碑删除。
20. 未知版本与损坏互动文件阻止新增/删除且不覆盖原内容；宿主空字符串可首次保存，恢复合法文件后可继续追加。
21. 互动导出保留原始损坏项、重复项与未知版本字段，兼容原有归一化字段，不修改存储。
22. 设置页备份读取失败显示错误且不下载，重试后生成包含完整原始快照的 JSON 下载；下载动作使用替身。
23. 互动备份预览零写入，合并重读当前库保留并发新增；重复及并发导入幂等，损坏当前库禁止覆盖。
24. 设置页备份恢复先预览再确认；坏文件清空旧计划、迟到预览不能覆盖、取消不写入、失败可重试，成功刷新并清空文件；文件选择框不超出移动边界。
25. 禁用浏览器 Web Locks 后并发保存 12 位参与者仍保留全部记录；并发备份合并只新增一次，不覆盖旧记录。此项验证同一 JS 上下文，不证明跨窗口互斥。
26. 人物互动每批 20 条、可加载更多，搜索和来源筛选可清除；长备注换行不溢出。删除取消不写入，失败可重试，成功刷新时间线/同场统计并保留其他参与者。
27. 单条互动删除在存储锁内校验人物归属，不属于当前人物的事件拒绝删除。
28. 图谱关系中心高亮直接邻接，两人对比仅展示显式关系的共同联系人；查询不重建画布，结果可打开人物详情。清除恢复全图，孤立节点空态明确，筛选后清理失效选择，移动视口控件不越界。
29. 两人对比切换最短路径后展示有序人物链与关系段数，仅高亮路径连线；直接关系是一段，无连接清除旧高亮，切回共同联系人与清除选择仍正常，链路人物可打开详情。
30. 单人查询切换严格二度关系，结果排除中心/直接邻接，保留中间人物与连接高亮且不重建画布；无二度结果显示空态。无关系筛选按完整名册判断，不因搜索隐藏对端而误报，清除筛选重置开关并恢复图谱。
31. 两个独立同源 iframe 分别加载真实存储模块，共享隔离 localStorage：浏览器锁查询证明另一上下文进入等待队列；12 人并发新增、重复身份、预览零写入、删除/旧备份/新增并发、失败释放锁与同备份并发合并保持计数、墓碑和内容正确。
32. 使用真实英文资源挂载工作台，验证导航/四视图标题、无障碍标签、设置入口、人物详情标题及关闭；空翻译回退中文，移动视口导航不越界。
33. 设置页导出中心显示名册人数与活跃互动条数、格式与「都不是完整备份」范围说明；vCard 导出失败不下载、重试成功生成 .vcf；空名册禁用导出并提示。数量摘要是容错读取，失败不显示数量也不阻塞导出。
34. 联系人表格列设置：姓名列固定不可取消，可选列勾选显隐与上下移动即时生效并持久化；重开恢复列顺序；恢复默认回到卡片视图与全列。偏好归一化（缺字段默认、非法/重复键剔除、清空回退全列）由单元测试覆盖。
35. 组合筛选：标签全部/任一交集并集、最近互动日期范围（闭区间端点、无互动者排除）、从未联系的数量与生效条件行一致；条件 chip 单项清除、「清除全部」不遗留隐藏条件并重置标签匹配与从未联系开关。交并集与日期端点语义由单元测试覆盖。
36. 保存视图：命名保存当前筛选与排序、同名保存按确认覆盖、改名与删除只改规则不改人物与当前列表；应用后条件漂移即取消视图标记；含失效标签的视图应用时明确提示且其余条件照常生效；重开恢复规则。归一化（非法条目丢弃、坏日期容错、按 id 去重、上限截断）由单元测试覆盖。
37. 跟进事项（F05）：Peek 创建日期型计划（挂起中重复提交不新增）、推迟菜单传递语义选项（明天/三天后/下周一/次月/指定日期）、完成与取消传递状态并刷新；首页待办分逾期/今天/近期展示，「处理」仅对可达人物出现并打开详情，不可达人物仍可推迟/跳过，完成或跳过不自动写互动；备份预览零写入、合并现状优先按 id 幂等、当前库损坏与坏备份拒绝、导出读取失败不生成空备份；非法日期创建被拒绝且零写入。推迟日期计算与分桶排序由单元测试覆盖（固定时钟）。
38. 联系节奏（F06）：按人覆盖阈值后 20 天前互动在自定义 14 天下进入久未联系、补录 40 天前旧互动不覆盖较新记录、暂停整体隐藏、清除覆盖回退全局；Peek 节奏设置显示当前规则与上次互动，自定义/暂停/清除持久化并触发首页刷新。归一化（非法键值丢弃、days 钳制 1–365、包络损坏抛错）与阈值边界由单元测试覆盖。
39. 今日行动清单（F07）：生日+节奏+跟进三源按人聚合，同一人多原因只出一张卡、徽标按紧急度着色排序；逾期跟进提供「批量顺延到今天」（逐条语义推迟），完成后清单与空态刷新；打开详情不误触发。桶优先级排序、窗口排除与多原因聚合由单元测试覆盖（固定时钟）。
40. 打开摘要（F08）：有行动且当日未忽略时横幅显示且数量与行动清单同源；「今日不再展示」持久化当天日期实现同日抑制、次日恢复；关闭偏好后不显示；空清单不出横幅。偏好归一化（缺字段默认、非法日期清空）由单元测试覆盖。
41. 互动备注模板（F09）：空存储回退内置默认（见面/电话/聚会）不落盘；选用模板填入备注并本地替换 {{姓名}}/{{日期}}/{{上次互动}}，已有草稿需确认覆盖、拒绝则不改写；管理弹窗增改删全量落盘、重开恢复、取消删除不写入、非法条目归一化丢弃；模板文本不发送 AI、不自动提交。归一化与占位符替换由单元测试覆盖。

移动视口额外检查底部导航固定定位、联系人切换、全屏 Peek 宽度和安全区底部内距。

图谱搜索的结果计数、聚焦和悬停摘要，仪表盘生日横幅，设置页下载动作、字段映射校验以及 AI 来源徽标通过类型检查和生产构建验证；当前隔离回归重点覆盖状态竞态和宿主弹窗行为。

这套检查验证组件行为与服务调用链；内核响应和宿主 Dialog 是替身。跨上下文测试验证同源浏览器 Web Locks 与真实存储服务代码，但持久化是隔离 localStorage，不是思源文件，也不是两个实际思源窗口。它不证明真实 AV 写入、宿主多窗口并发、移动端触控/软键盘或完整视觉布局正确。无 Web Locks 时仍只保证同一 JS 上下文排队；按用户最新要求，实际宿主验证跳过，范围与未验证风险保留在 `docs/RELEASE.md`，不阻塞继续开发。
