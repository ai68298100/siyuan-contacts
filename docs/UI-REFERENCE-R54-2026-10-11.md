## 核心结论

R54 的舒适感来自清楚的任务主次、平静的普通表面、连续留白及少量有目的的色块。普通卡片主要通过白色表面与 1px 轻描边建立边界，明显投影集中在窗口。首页先给出一个可以开始的主行动，统计、回顾与辅助操作退到次级位置。

当前人脉已经使用白色卡片，但原型仍同时强调页头、统计、面板标题、工具栏、状态说明与多种框线；后续追加的材质样式又给侧栏、卡片、按钮和输入框叠加高光、投影或渐变。调整重点应覆盖信息架构与基础组件，并清理重复样式层。

## 人脉页面映射

1. **首页**：先建立清楚的今日主行动和一个主要入口；统计使用辅助指标带；次级联系、未来提醒和上手引导分别形成平静区块。仍能访问全部行动与其触发原因。
2. **联系人**：统一页头、搜索和筛选，主要操作有明确位置，批量工具按选择状态出现；人物卡片使用更宽松的内边距与资料层级。
3. **组织**：采用同一白色卡片、文字和按钮配方；40px Logo、长名称、状态及成员操作使用稳定位置。
4. **人物详情与编辑**：采用正常窗口和连续内容分组，减少重复面板框线；资料、历史、来源、未知及保存状态仍清楚可读。
5. **图谱与设置**：工具随任务分组，状态就近显示；把主要操作、辅助动作与帮助说明分开排版。

## 实施约束与验收

- 人脉使用青色操作与白色内容面的现有方向，参考 R54 的结构、留白和表面关系。R54 的学习文案、统计和示例数据不进入人脉事实。
- 人物详情按用户最新要求使用正常居中窗口；R54 自身另有右侧详情抽屉，该承载方式不作为人脉迁移目标。
- 普通卡片的默认态不靠厚阴影或全域装饰建立质感；首用及少量首页提示可使用与人脉相关的本地轻插画。
- 从 tokens、共用控件和工作台布局开始调整，随后组合页面；修改原规则并清理重复覆盖，避免继续追加一层全局增强样式。
- 原型优先演示正常使用，再切换空态、读取失败、未知、保存与草稿状态；每页的主任务需要在首屏可辨认。
- 每轮同时核对桌面、窄容器、明暗主题、长中文与联系方式；窗口关闭、焦点、滚动、移动输入法及跨页返回沿用已验证的交互要求。

本轮已落实：生产工作台桌面侧栏收窄至 192px、内容区上限 1240px，普通内容面统一白色轻描边并移除静态阴影/装饰高光，设置页只保留一个可见页标题；原型同步使用相同尺寸和表面规则。人物详情仍按产品要求使用居中窗口。桌面与移动 UI 回归分别通过 342/342、343/343，后续新增页面应继续遵守本基线。
